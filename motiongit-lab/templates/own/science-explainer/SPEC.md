# 科普视频版式 · 蒸馏报告

> 源片：`d6ef49c88c4766217c388678d9ba7aca_raw.mp4`（153.64s / 960×544 / 28fps / 4302 帧 / AAC 44.1k 立体声）
> 产出：本目录 `.motion` 模板包（1920×1080 / 30fps / 8 类版式 / 纯 canvas 2D 绘制）
> 定位：**复刻信息语法，不复刻画面素材**。原片的插画、器官图、角色、文案、品牌标识均未复制。

---

## 一、先给结论

这支片子看起来是"卡通动画"，实际结构是**信息卡片的序列**。48 个镜头里没有一个镜头在"表演剧情"，每个镜头都在完成一个明确的信息动作：

| 信息动作 | 镜头数 | 占比 | 画面特征 |
|---|---:|---:|---|
| 人物讲解（换气 + 人脸锚点） | 18 | 37% | 半身固定机位，一侧留白 |
| 图解释意（解剖/器械/原理） | 16 | 33% | 圆框放大 + 引线标注 |
| 标签强调（一个词打出来） | 5 | 10% | 梯形标题条 + 圆卡 |
| 阵列枚举（病种清单） | 3 | 6% | 图标 + 胶囊标签 |
| 新旧对比 | 2 | 4% | 左右卡片 + 红箭头 |
| 首尾 | 2 | 4% | 爆炸贴 / 斜切条 |
| 场景建立 | 1 | 2% | 走廊 + 门牌 |

⇒ **科普片 = 1/3 人物 + 1/3 图解 + 1/3 标签**。人物不是主角，是节奏控制器；图解不是插画，是论据；标签不是装饰，是记忆点。

这个比例直接决定了模板该提供什么：不是"角色动画系统"，而是**8 个信息版式 + 一套标签语汇 + 一条字幕轨**。

## 二、实测数据

### 2.1 切点与节奏

用帧差法（4fps 采样、灰度、相邻帧平均绝对差）检测，阈值 mean|Δ| > 8 得 **48 个切点**：

| 指标 | 数值 |
|---|---|
| 镜头总数 | 49（含首尾） |
| 最短镜头 | 0.75s |
| 中位镜头 | **2.75s** |
| 平均镜头 | 3.03s |
| 最长镜头 | 6.25s（封面） |
| 前 1/3 平均 | 2.9s |
| 后 1/3 平均 | 4.6s |

**节奏规律**：开场密（0.75–2.5s 快切建立信息密度），中段稳（2.5–3.5s 讲机制），收尾慢（4–6s 给结论留时间）。

切点跟着**句子**走，不跟动作走。口播一句 2–3 秒，一个镜头就是一句话。

### 2.2 配色

对全片抽帧做 k-means（k=10）：

| 色值 | 占比 | 用途 |
|---|---:|---|
| `#F8FAE7` | 19.4% | 讲解位奶油底 |
| `#C6E5E3` | 17.8% | 青绿格子纸（图解） |
| `#7DCEE5` | 13.2% | 蓝格子纸（信息/卖点） |
| `#E8CCAE` | 9.3% | 木色/暖色道具 |
| `#F8FAFA` | 8.3% | 高光/白大褂 |
| `#F8EDCD` | 8.1% | 奶油黄辅色 |
| `#ECAB85` | 7.2% | 器官/皮肤 |
| `#769994` | 6.2% | 青灰阴影 |
| `#4D3F45` | 5.4% | 头发/深色锚点 |
| `#B7753C` | 5.1% | 外套棕橙 |

强调色（局部采样）：

| 色值 | 用途 |
|---|---|
| `#FD2551` | 爆炸贴洋红、病灶标记、划除线 |
| `#FFD84D` | 标签黄、荧光笔、圆卡底 |
| `#26A38C` / `#0E7A5F` | 标题条青绿（浅/深） |
| `#2B7FD4` | 斜切标签蓝边 |
| `#F4A492` / `#E07C6A` | 器官粉（亮/暗） |

**规律**：背景永远低饱和（明度 88–96%），所有高饱和色只出现在**标签、爆炸贴、除标线、器官**上。信息靠色彩对比跳出来，不靠亮度。

### 2.3 字幕规范

| 项 | 实测（@960 宽） | 换算 @1920 |
|---|---|---|
| 位置 | 底部居中，baseline ≈ 0.96H | y ≈ 1002 |
| 字高 | 34px | 64–68px |
| 颜色 | 纯白 | `#FFFFFF` |
| 描边 | 深色粗描边，约 4px | 8–10px |
| 底衬 | 无底衬（纯描边） | 同 |
| 单行字数 | 8–14 字 | 同 |
| 每句停留 | 2.3–2.8s | 同 |

**这是全片最主要的信息通道**：画面标签是"关键词"，字幕是"完整句子"，两层信息、两级字号（100px 标签 : 33px 字幕 ≈ 3:1）。

### 2.4 品牌角标

左下角，距边 10–20px，高约 120px（含卡通 IP + 品牌字），垂直位置 ≈ 0.86H。**始终在字幕上方**，不与字幕争同一条水平带。

## 三、版式语汇（蒸馏出的 8 类）

| 模板版式 | 对应源片镜头 | 关键特征 | 承载内容 |
|---|---|---|---|
| `cover` | 0–5.5s 爆炸贴封面 | 半透明白横条 + 洋红爆炸贴 + 双色标题（白字蓝边 / 白字红边） | 一次钩子 |
| `talk` | 18 个讲解员镜头 | 半身固定位 + 一侧留白放要点 + 问号/盾牌贴纸 | 观点、设问、总结 |
| `diagram` | 8 个圆框解剖 | 格子纸 + 白圆盘 + 拟人化器官 + 探头声波 + 引线标注 + 荧光笔 | 机制、病灶、原理 |
| `compare` | X 光 vs 超声 | 左右卡片 + 红箭头 + 对/错角标 + 底部金句条 | 新旧方案 |
| `matrix` | 三病种/四病种圆卡 | 图标 + 胶囊标签，单行或 3×2 | 清单、适用范围 |
| `focus` | 安全无辐射 / 快速实时 / 用途广泛 / 可辅助治疗 | 梯形标题条 + 黄底圆卡 + 被划掉的旧认知 | 单点卖点 |
| `tip` | 123–128s 便签卡 | 胶带 + 折角 + 横线纸 + 勾选条目 | 三点小结 |
| `outro` | 147–153s 尾板 | 两条斜切色块 + 白字投影 + 免责声明 | 收尾 |

### 标签语汇（贯穿全部版式）

1. **黄底蓝斜边标签**（`tagSun`）：贴在任何图旁边做名词标注，如「超声耦合剂」
2. **深绿梯形标题条**（`bannerJade`）：版式标题，如「用途广泛」「快速实时」
3. **手写感红字 + 白边**（`handText`）：直接写在图上，如「发炎的阑尾」
4. **荧光笔划痕**（`marker`）：划重点，永远半透明、圆头、微微弯
5. **胶囊标签**（`matrix` 用）：图标下方，深青底白字
6. **爆炸贴**（`burst`）：只用一次，只在封面

## 四、参数化设计

### 4.1 时间轴

```json
{ "segments": [ { "type": "talk", "dur": 6.0, "args": { ... } } ] }
```

- 段与段**硬切**，无转场（源片就是硬切）
- `durationSeconds` = Σ`dur`，必须一致
- 所有入场动画在段首已推进 20–30%，**切点处不出现空帧**（这是实测发现的关键约束：源片每个切点第一帧就有完整画面）

### 4.2 三层信息

| 层 | 参数 | 字号（@1920） | 作用 |
|---|---|---|---|
| 画面标签 | `args.title` / `args.eyebrow` / `args.label` | 44–92 | 关键词，扫一眼记住 |
| 图解标注 | `args.callouts[].text` | 70 | 论据，指哪打哪 |
| 口播字幕 | `captions[].text` | 62 | 完整句子，听懂逻辑 |

三层字数上限：标签 ≤ 6 字、标注 ≤ 10 字、字幕 ≤ 20 字。**超了就换版式，不要缩字号**。

### 4.3 素材边界

- `talk.figureImage`：可挂透明底 PNG（真人抠像或外包插画）。缺省时画**内置扁平讲解员**（可改发色/肤色/外套色），不是剪影占位符。
- 器官图标全部为代码绘制的矢量近似（结肠、胃、胆囊、阑尾、肾、子宫、肠套叠示意），**不是医学精确图**。用于示意可以，用于诊断宣教必须换成持证插画。
- 模板不生成语音、不生成配乐。需要配音用 `--audio` 传入。

## 五、验证

| 项 | 结果 |
|---|---|
| 参数校验 | `✓ 校验通过`（preset 全字段符合 schema） |
| 渲染 | 1635 帧 / 54.5s / 1920×1080@30 / 6 路并行 / 10.15s（≈161 fps） |
| 文件 | 4.92 MB（5,162,076 B），H.264 CRF18 + yuv420p |
| 交付门禁 `skia-kit/gate.mjs` | **PASS**（空帧 0.0%、黑帧 0.0%、hook 0.49、帧数 1635/1635） |
| 音轨 | AAC 44.1kHz 单声道，`tools/vo.py` 生成的 TTS 配音（-16 LUFS）；原 54.5s 脚本配完音变 73.8s |

**未做的事**（诚实记录）：
- 没有复刻原片的实景走廊背景与真人抠像，`cover` 默认改用柔光色块底纹
- 器官图形是示意级，不追求解剖准确
- 未做竖屏版本；竖屏需要重排版式，不能裁切
- 字体依赖系统苹方，粗标题用同色描边膨胀（`heavy = size × 0.05`）补足字重；跨平台（Windows）会回退到微软雅黑，字重观感会变

## 六、复用方法

```bash
# 1. 换一套文案（presets/ 里有两支现成的：demo 医学科普、microwave 厨房辟谣）
cp presets/demo.json presets/我的脚本.json   # 改 captions / segments 的文案与时长

# 2. 校验 + 预览关键帧
node motion-render.mjs preview --package templates/own/science-explainer --style 我的脚本 --out out/preview

# 3. 出片（有配音就加 --audio）
node motion-render.mjs render --package templates/own/science-explainer --style 我的脚本 --out out/我的片.mp4 --jobs 6

# 4. 过门禁
node skia-kit/gate.mjs out/我的片.mp4
```
