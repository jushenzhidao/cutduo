---
name: chart
一句话: 先用轴搭好一个空坐标系，再让数据长出来，最后只标一件事——观众会截图较真的数字，宁可少画不能画错
适用: 营收/占比/走势/对比；口播里出现"涨到""从 A 到 B""差了 N 倍"这类可以量化的句子
时长: 单张 2.5–6s；超过 6s 应该拆成两屏（先看全貌、再标一处）
能量: 中（画面自己在长，不需要再叠运镜）
标签: dataviz / 静态构图
---

## args

| 字段 | 类型 | 说明 |
|---|---|---|
| `chart` | `'line' \| 'bar'` | 缺省 `line` |
| `series` | `[{ points: [[x,y],…] }]` | 折线用。x 是数值轴上的位置，不是序号 |
| `items` | `[{ value, label? }]` | 柱状用。**柱一律从 0 起**，不给基线就是错的 |
| `axis` | `{xFrom,xTo,yFrom,yTo}` | 不给就按数据推（上下各留 8% 余量） |
| `at` | 秒 | 数据开始生长。缺省 `t0 + 0.4` |
| `stagger` | 秒 | 逐个落点的间隔，缺省 0.12 |
| `title` | 字符串 | 上方标签 |

绘图区固定为左半画幅 `x∈[300,1080] y∈[392,716]`（硬编码，不是参数）——右边留给关键词卡。
要更宽的图，需要改代码里的 `X0/X1`，并同步跑 `verify.mjs`。

## 意图

口播里最难讲的是"量级"。形容词（"大幅增长"）观众记不住，"2.3 倍"记不住，"这条线从这里走到这里"记得住。

chart 段型的职责是把一句话里的**数量关系**变成一个可被眼睛验证的形状。它不负责好看，负责**能被较真**：观众截图放大之后，数字要对得上。

## 参数表

| 参数 | 典型值 | 调节手感 |
|---|---|---|
| `at` | `t0 + 0.4` | 往前挪 = 轴还没画完数据就冒出来（读作"乱"）；往后挪 = 前 1 秒是空坐标系（可用于"先看全貌"）。口播说出数字那一刻应该是数据**落定**，不是开始长——反推：`at = 数字时刻 − 生长时长` |
| `stagger` | 0.12 | 0.06 = 一整片同时冒出来，看不出"逐个落点"；0.25 = 太慢，5 个点要 1.25s，口播已经说到下一句了 |
| `axis.yFrom/yTo` | 数据 min/max ±8% | **柱状图必须显式给 `yFrom: 0`**，否则柱子从半空长出来，视觉上夸大了差比。折线可以不从 0 起（但轴不 0 起要在文案里说清） |
| `axis.xFrom/xTo` | 数据 min/max | 显式给是为了留出"端点余量"：数据从画框边缘开始会长得像被裁断 |
| `series[].points` 长度 | 6–12 | <6 读作"散点"，>12 在 780px 宽里挤成一条粗线 |

## 已知坑

- **`freezedetect` 会把这个段型误判成"冻住"**。标记点占全帧 0.02%，低于 freezedetect 的 0.2% 阈值。数据长完之后画面确实不动，但那是有意的落版。**别为了过门加抖动**。
- 跨零的数据（有正有负）必须画零线虚线，否则观众以为全在轴上方。
- `bar` 模式**不画 x 轴数字**（代码里如此），所以「第 1 根是几月」这种信息必须写进 `title` 或口播，不能指望图上有。
- 同一屏只标**一处**。标 3 个点等于没标——观众不知道该看哪个。
- 数据必须是**真数据**。示意数据不能混进 chart（改用 `number` 段型讲单个数字）。

## 动效

轴先长（`t0+0.04` 起 0.46s）→ 数据按 `stagger` 逐个落点 → 标记点晚 0.2s 落定。
