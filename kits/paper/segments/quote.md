## args

| 字段 | 类型 | 说明 |
|---|---|---|
| `lines` | `["行1", "行2"]` | **字符串数组**，不是元组数组。`*词*` 走强调色 |
| `by` | 字符串 | 落款，31px、字距 7，在 `at+0.9` 处上浮 |
| `at` | 秒 | 打字机开始时刻（绝对秒） |

字号：所有行里最紧的 `fitSize(83, 780)`，**全段统一**。行距 119px，基线 `328 + i×119`。

## 意图

quote 的功能是**降速**。前后都是 point 或 number 时，画面一直在"给信息"；quote 让观众从"接收"切换到"咀嚼"。

打字机不是装饰：它把阅读速度强绑在时间轴上——打多快，观众就读多快。所以 `at → at+1.1` 打完这个时长是**信息密度的度量**，字数越多，每个字停留越短。

## 参数表

| 参数 | 典型值 | 调节手感 |
|---|---|---|
| `lines` 数量 | 2–3 行 | 每行 780px 宽、83px 上限 ⇒ 单行约 9–10 字。3 行 = 27 字上限；再多会压到落款（y=716） |
| 单行字数 | 8–12 | 超过 12 字字号被压到 70px 以下，与 point 标题抢戏；低于 6 字撑不满宽度，右边空 |
| 打字总时长 | 1.1s（写死） | 不能调。中文 30 字 / 1.1s ≈ 27 字/秒，接近阅读速度上限。要更慢只能减少字数 |
| `at` | 段首 + 0.3 | 早于 `t0` 会导致 `pr()` 负值，整段无字。晚于段首 1s 则前 1 秒只有一个空引号 |
| `by` | 10 字以内 | 31px + 字距 7，长署名会顶到右边；字距是 `drawChars` 的第 6 个参数，不是 CSS |

## 已知坑

- **`lines` 是字符串数组**，写成 `[["文案", 0.4]]` 不会报错，但每个元素会被 `String()` 成 `"文案,0.4"`——画出奇怪的文字。这是 paper 里唯一一个"字符串数组"的段型（`point.words` 和 `hero.lines` 都是元组数组）。
- **除最后一行外，会自动补中文逗号**。代码：`!/[，。、；：！？,.;:!?]$/.test(l)` 时追加 `，`。所以 `lines: ["第一行", "第二行"]` 会渲染成"第一行，第二行"。不想要这个逗号，就得自己在行尾加标点（任何标点都会阻止追加）。
- 打字机光标是**脉动**的（`0.2 + 0.7×(0.5+0.5sin(t×10.8))`），不是硬开关。硬闪在视频里读作丢帧。
- 光标的 `if (p > 0 && p < 0.999 && budget < chars.length)` 意味着**只在正在打的那一行**出现，且打完后消失。
- `by` 的入场在 `at+0.9`，早于打字结束（`at+1.1`）。所以落款会在最后一个字打完前 0.2s 冒出来——这是有意的（避免"打完再等落款"的双重停顿）。

## 动效

大引号 0.88→1 倍、0.02–0.5s 淡入（`rgba(30,138,102,0.20)`，210px）→ 逐字打字 1.1s，光标跟随 → 落款 31px 字距 7 在 `at+0.9` 上浮 8px。
