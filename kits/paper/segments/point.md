## args

| 字段 | 类型 | 说明 |
|---|---|---|
| `words` | `[["文案", 绝对秒], …]` | 拼成一整行标题。`*词*` 走强调色 |
| `cards` | `[["文案", 绝对秒], …]` | 正文行，40px，从 `y=491` 起每行 62px |

标题字号 `fitSize(title, 116, 916)`——**按拼起来的整行算**，不是逐词。
几何固定：大弧圆心 `(668,872)` R=757，从左下扫入。

## 意图

point 是 paper 里最像"教科书"的段型：一个概念 + 两三行解释。它的构图是**上下分层**的——标题在中上部、正文在中下部、大弧把两者包在一起。

强调词是它唯一的"情绪出口"：荧光底（`rgba(30,138,102,0.16)`）+ 4px 下划线。一个段里只标一处。

## 参数表

| 参数 | 典型值 | 调节手感 |
|---|---|---|
| `words` 数量 | 2–4 个片段 | 拼接后总字数 8–16。超过 16 字标题会被压到 90px 以下，与 hero 抢戏 |
| `words[i][1]` | 段内 0.3–1.2 | 各片段间隔 0.3–0.5s，读作"一个词一个词蹦出来"。间隔为 0 时整行同时揭示，失去节奏 |
| `cards` 数量 | 2–3 行 | 第 3 行落在 `y=615`，第 4 行到 `y=677` 就开始压字幕带（字幕在 920 以下，还行，但视觉上挤） |
| `cards` 单行字数 | 8–14 | 40px × 14 字 ≈ 560px，居中后左右各留 430px，舒服 |
| 强调词 | 1 个 | 荧光底的宽度是 `accW + 12`，词越长底越宽；3 字以内最好看 |

## 已知坑

- **`words` 的第三个元素没有实现**。`v8t.json` 里写着 `["*等下一版*", 6.849, "slam"]`，但 `pPoint()` 只读 `[0]` 和 `[1]`——`'slam'` 是死数据，不会有任何砸入效果。要砸入得自己实现，或者别写。
- `words` 的时刻是**绝对秒**，不是段内相对。写成 `0.5` 会被当成"第 0.5 秒"（整片开头），卡片永远不会出现。锚点用 `{$mark}`（`{$markRel}` 会被减掉 t0，得到负数）。
- 标题宽度 `tw` 是按拼接后的字符串算的，所以 `words` 分几段不影响排版，只影响揭示节奏。
- 大弧的时间基准是 `a.t0 + 0.04 → a.t0 + 0.94`，**写死相对段起点**，不受 `words[i][1]` 影响。改标题时刻不会改弧的速度。
- 荧光底在 `startAt + 0.45 → startAt + 0.9` 扫出，`startAt` 是第一段的时刻。如果第一段给得太晚，荧光底会拖到段尾。

## 动效

大弧 0.9s 从左下扫入（之后完全静止）→ "重点"标签 0.05–0.4s → 标题逐片段揭示 0.6s + 上浮 14px → 荧光底扫过 + 下划线 → 正文行各 0.4s 上浮淡入。
