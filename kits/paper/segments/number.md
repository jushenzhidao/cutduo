---
name: number
一句话: 把一句话压缩成一个数字，用圆环的进度和数字的滚动同时说明"它有多大"和"它占多少"
适用: 误差上限、命中率、占比、倍数；口播里只有一个数、且这个数要被人记住
时长: 2.5–5s（环入场 0.5s + 数字滚动 `dur` + 说明 0.35s）
能量: 低（画面几乎不动，靠数字本身承载信息）
标签: single-number / 静态构图
---

## args

| 字段 | 类型 | 说明 |
|---|---|---|
| `label` | 字符串 | 圆环上方的小标签（"误差上限""命中率"） |
| `value` | 数值 | 终值 |
| `unit` | 字符串 | 紧跟数字的单位（`%` `倍` `人`），66px，强调色 |
| `from` | 数值 | **滚动起点**（不是时间）。缺省 0 |
| `dur` | 秒 | 数字滚动时长，缺省 1.4 |
| `at` | 秒 | 开始滚动，缺省 `t0` |
| `sub` | 字符串 | 圆环下方一句说明，在 `at + dur*0.85` 处上浮 |

几何固定：圆心 `(670,418)`、外环 R=265、36 条刻度、数字 172px。要改需同步 `verify.mjs` 的期望值。

## 意图

一屏只放一个数。数字要大（172px，占了画面高度的一半），因为它的作用是**被记住**，不是被读。

圆环不是装饰：它把 `value` 相对于某个满分变成"走了多少"。所以 `value` 应该是"占整体的比例"，不是一个绝对值——讲"3000 万"这种绝对量应该用 `chart` 或大字，圆环会误导（占谁的 3000 万？）。

## 参数表

| 参数 | 典型值 | 调节手感 |
|---|---|---|
| `from` | **等于 `value`**（见下） | 见「已知坑」第一条，这是本段型最容易出错的地方 |
| `dur` | 1.2–1.6 | <0.8 读作"闪现"，数字没有"涨"的过程；>2.2 观众开始等它停 |
| `at` | `t0` | 口播说出这个数的那一刻应该是数字**停稳**，不是开始滚。反推：`at = 说话时刻 − dur` |
| `unit` | 单字或双字 | `%` `倍` 最好；"个百分点"这种四字单位会顶到右侧关键词卡（66px × 4 字 ≈ 264px） |
| `sub` | 15 字以内 | 42px，居中在 `y=693`。超过 20 字会跟字幕条打架 |
| `value` 位数 | ≤5 位 | 172px × 6 位 = 1032px，超出圆环直径（530px）会读作"数字从环里溢出来" |

## 已知坑

- **`from` 不要写 0。** 这是本段型最贵的一条。滚动过程中每一个中间值都会清晰地显示 172px 那么大——如果标签是"误差上限"而终值是 1%，观众会先看到 0%、0.3%、0.7% 这些**不存在的事实**。正确做法：`from = value`，数字不滚，只让圆环从 0 走到 100%。代价是 `freezedetect` 会多算 1s 静止，可接受。
- **不给 `dur` 时数字瞬间到位**，整段随后完全静止（`p` 立刻到 1，环也不动）。要么给 `dur`，要么这段就只靠 `sub` 入场来提供变化。
- 圆环的"进度"是 `(value − from) / value` 的缓动，不是真实比例。要表达真实占比（如 62%），必须 `from = 0` 且 `value = 62`——但那样就会踩第一条的坑。**取舍**：要么数字不滚（`from = value`）而环失准，要么数字滚而中间值误导。当前设计选前者。
- 同一支片里 `number` 段的字号不随字数缩放（固定 172px），换长短数字会看出"大小不一致"，这是有意的——数字是版面主角，不该跟着字数变。

## 动效

环入场：0.9 倍半径扩到实际大小（`t0+0.04` 起 0.46s）→ 36 条刻度随进度逐条点亮 → 数字 `easeOutQuart` 滚动（前段冲、末段收）→ `sub` 在 `at + dur*0.85` 上浮 8px 淡入。

环的白色描边（lineWidth 6，`arc` 到 `prog` 处）是"走了多少"的唯一视觉指示；刻度只是陪衬。改 `prog` 的缓动会同时改变两者的节奏。
