---
name: grid
一句话: 用点阵把"很多个"变成一个能数得过来的形状，再把那个不该存在的点从网格里拔出来
适用: 讲基数、讲概率、"万里挑一"、讲幸存者偏差这类"群体里有一个例外"的内容
时长: 4–8s（点阵铺满 + 例外跳出 + 说明落版，少于 4s 观众数不过来）
能量: 中（点阵自己在逐个出现）
标签: quantity / 静态构图
---

## args

| 字段 | 类型 | 说明 |
|---|---|---|
| `rows` / `cols` | 整数 | 点阵行列。10×10 是最常见的口径（"一百个人里"） |
| `gap` | px | 点间距，缺省 30。`cols×gap` 就是整块点阵的宽 |
| `size` | px | 点的半径，缺省 9 |
| `origin` | `[x,y]` | 左上第一个点的位置，缺省 `[300,392]` |
| `at` | 秒 | 第一个点出现的时刻，缺省 `t0` |
| `stagger` | 秒 | 每个点之间的间隔，缺省 **0.008** |
| `highlight` | `[[i,j],…]` | 高亮点（强调色），用于"这几个是我们要的" |
| `exception` | `[i,j]` | 例外点：**跳出网格** + 2.2 倍半径 + 虚线牵回原格位 |
| `title` | 字符串 | 上方标签，自动按点阵中心对齐 |
| `note` | 字符串 | 底部一句人话（"一百个人里只有三个"） |
| `noteSize` | px | 说明字号，缺省 46 |

## 意图

"一百个人里只有一个"这句话，说出来是数字，画出来是**尺度**。点阵的作用是让观众在 0.5 秒内感到"这么多"，而不需要读任何字。

`exception` 是这套段型的核心机制，不是装饰：它必须**跳出网格**。留在格子里只换颜色，读作"这个被高亮了"；跳出去才读作"它不属于这里"。

## 参数表

| 参数 | 典型值 | 调节手感 |
|---|---|---|
| `stagger` | 0.008 | 100 个点 × 0.008 = 0.8s 铺满。调到 0.02 就变成 2s，观众会开始"等"；调到 0.003 读作一次性闪现，失去"逐个落位"的节奏 |
| `gap` | 30 | 10 列 × 30 = 300px 宽（画幅 1920）。gap 加大到 44 会顶到右侧关键词卡；小于 24 点会糊成一片灰 |
| `size` | 9 | 与 gap 的比例要在 1:3 左右。size 接近 gap 时点会粘连；size < 6 在 480 宽带检查图里几乎不可见 |
| `exception` 的位移 | 代码写死 `+2.6gap / −1.9gap` | 这是"跳出画面主要阅读区"的量。要改必须同时改虚线的起点，否则牵回线会指向错的地方 |
| `highlight` 数量 | 0–6 | 超过 6 个就失去"少数"的含义，此时该用 `chart` 而不是 grid |
| `note` | 一句 15 字以内 | 点阵本身不解释自己。没有 note 的 grid 只在口播已经说清数量时成立 |

## 已知坑

- **例外点必须跳出网格**，不能只换色、不能只换形状。我们试过换方形——在 9px 的尺度下分不出来；也试过只换色——读作"高亮"而不是"异常"。跳出 + 2.2 倍 + 虚线牵回，三者是一套，缺任何一个都会降级成普通高亮。
- **标题对齐不是 `(ox + 全宽)/2`**。点阵的实际宽度是 `(cols−1)×gap`（最后一个点之后没有间距），按全宽算会整体偏左半个 gap。代码里用的是 `ox + (cols−1)*gap/2`。
- 点阵**不代表精确数量**。它表达"很多"，不是"正好 100 个"。要精确就写进 note。
- 100 个点的 `stagger` 总时长 = `rows*cols*stagger`，`note` 的入场时刻是从这个总和之后算的。改 `stagger` 会连带推迟 note，别只改一个。

## 动效

逐个落位（每个点 0.30s 的缓出）→ 例外点额外晚 0.12s 出现，然后向外跳 + 虚线牵回 → note 在点阵铺完后 0.15s 淡入。
