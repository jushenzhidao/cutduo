渲染服务接口文档

面向调用方（Agent / 业务后端）的 REST 契约。所有示例都是真实请求与响应； 错误码是契约，message 只是叙事 —— 请按 code 决策。

Base URL http://127.0.0.1:8787 版本 v1 认证 Bearer token 编码 UTF-8 / JSON

00基础约定

鉴权

Authorization: Bearer <token>，token 与租户一一映射 （RENDERD_TOKENS="token:tenant,token2:tenantB"）。下载类端点额外支持签名 URL， 便于 Agent 直接取。鉴权失败也有限速：同一 IP 的无效令牌超过 RENDERD_AUTH_FAIL_QPS （默认 10/s）返回 429。

幂等

提交必须带 idempotency_key（≥8 字符）。唯一约束是 (tenant, key)： 同 key 重复提交返回同一 job_id 且不二次计费；不同租户用同一个 key 互不影响。

错误结构

{"error": {"code": "E_MEDIA_TOO_SHORT", "message": "...", "retryable": false,
          "stage": "ingesting", "field": "tracks[v1].clips",
          "allowed_values": ["out_frame <= 200"]},
 "request_id": "9f3d2a1c"}

retryable=true 才重试；field 指出改哪里，allowed_values 给出可接受范围。 完整列表见 错误码。

限流与背压

层触发返回
租户 QPS1 秒滑动窗口（20 × 50ms 子桶）429 E_RATE_LIMITED
认证失败同 IP 无效令牌 > 10/s429 E_RATE_LIMITED
队列深度全局排队数 ≥ RENDERD_MAX_QUEUE_DEPTH429 E_QUEUE_FULL
租户在途该租户 accepted+running ≥ RENDERD_MAX_TENANT_INFLIGHT429 E_QUEUE_FULL

任务状态机

accepted → running → succeeded
    ↑          │
    └──────────┴─→ failed（可 replay）    accepted → cancelled

stage：queued → ingesting → compiling → rendering → validating → delivering → done。 阶段比百分比有用：ingesting 失败是素材问题，rendering 失败是资源问题。

00三步跑通

# 1. 上传素材
curl -X POST $BASE/v1/assets -H "Authorization: Bearer $TOKEN" \
     -H "X-Filename: clip.mp4" --data-binary @clip.mp4

# 2. 提交（idempotency_key 用你自己的任务号）
curl -X POST $BASE/v1/render -H "Authorization: Bearer $TOKEN" \
     -H "Content-Type: application/json" -d '{
       "idempotency_key": "order-001",
       "template_id": "hook_vertical_6s",
       "variables": {"clip": "a0", "hook": "第一性原理"},
       "assets": [{"id": "a0", "uri": "upload:<sha>.mp4"}]}'

# 3. 轮询（成功后 video_url 可直接打开）
curl $BASE/v1/jobs/$JOB -H "Authorization: Bearer $TOKEN"

更多可运行示例见 renderd/README.md。

01公开

GET/healthz

健康检查

存活探针。返回引擎版本、字体族数量、运行时长。不鉴权，可用于负载均衡探活。

响应

{"ok": true, "version": "0.1.0", "ir_version": "0.1",
 "engine": "ffmpeg version 7.1.5", "uptime_s": 128.4,
 "backend_default": "ffmpeg", "fonts_available": 68}
GET/metrics

Prometheus 指标

文本格式指标。默认只对回环与私网开放，来源不在 `RENDERD_METRICS_CIDRS` 内返回 403。

参数类型说明
来源 IP—必须在 RENDERD_METRICS_CIDRS 内

响应

renderd_jobs_total 128
renderd_queue_depth 3
renderd_jobs_running 2
renderd_clock_skew_seconds 0

可能的错误：E_METRICS_FORBIDDEN

02渲染主链路

GET/v1/templates

模板列表

返回模板 id、画面比例、时长、分辨率，以及每个变量的 schema（必填、最大字数、可选值）。

响应

{"templates": [{"id": "hook_vertical_6s", "aspect": "9:16",
  "duration_s": 6.0, "resolution": [1080, 1920],
  "variables": [{"name": "hook", "type": "text", "required": true, "max_chars": 14}]}]}
POST/v1/validate

预检（不渲染）

请求体与 `/v1/render` 相同（`idempotency_key` 可省）。返回逐项检查与**机器可执行**的 fixes，Agent 照改即可重试。不占队列、不计费。

参数类型说明
bodyobject见提交渲染；`dry_run` 无意义

响应

{"valid": false,
 "checks": {
   "ir_schema": {"pass": true},
   "assets_readable": {"pass": true},
   "font_coverage": {"pass": false, "error": {"code": "E_FONT_MISSING"}},
   "text_safe_area": {"pass": true},
   "audio_present": {"pass": true}},
 "fixes": [{"field": "styles.*.font_family", "action": "pick_font",
            "value": "Noto Sans CJK SC"}],
 "estimate": {"cost_cny": 0.0049, "render_s_p50": 3.0, "wall_clock_s_p50": 9.0}}

可能的错误：E_BAD_REQUEST E_IR_INVALID

POST/v1/render

提交渲染

提交任务。同步完成预检（IR / 素材 / 字体 / 安全区 / 容量），预检不过直接返回错误码，不进队列。`dry_run=true` 只算成本、不入队。

参数类型说明
idempotency_keystring，必填，≥8调用方自己的任务号；同 key 重复提交返回同一 job，不二次计费
template_idstring与 `ir` 二选一
variablesobject模板变量
assetsarray`[{id, uri}]`，uri 支持 `file://`（限 media 目录）与 `upload:<name>`
irobject直传 IR，跳过模板；见 docs/IR.md
prioritylow / normal / high默认 normal
callback_urlstring完成回调；提交期解析并钉住 IP，防 DNS rebinding
deliveryobject`put_url` 直传客户对象存储，见下
dry_runbool只算成本与 checks
backendffmpeg / mlt默认 ffmpeg
{
  "idempotency_key": "order-20261109-001",
  "template_id": "brand_vertical_15s",
  "variables": {"clip1": "a1", "clip2": "a2", "clip3": "a3",
                "title": "季度回顾", "music": "m1"},
  "assets": [
    {"id": "a1", "uri": "upload:9f3d....mp4"},
    {"id": "a2", "uri": "file:///data/media/b.mp4"},
    {"id": "a3", "uri": "upload:11ab....mp4"},
    {"id": "m1", "uri": "upload:77cd....m4a"}
  ],
  "priority": "normal",
  "callback_url": "https://example.com/hook"
}

响应

202 Accepted
{"job_id": "job_35111bb1c430", "status": "accepted", "stage": "queued",
 "idempotent_replay": false, "poll_after_s": 3,
 "estimate": {"cost_cny": 0.0123, "render_s_p50": 7.5, "wall_clock_s_p50": 13.5}}

可能的错误：E_BAD_REQUEST E_IR_INVALID E_TEMPLATE_NOT_FOUND E_TEMPLATE_VARS E_FONT_MISSING E_TEXT_OVERFLOW E_QUOTA_EXCEEDED E_QUEUE_FULL E_RATE_LIMITED E_CALLBACK_FORBIDDEN

03素材

POST/v1/assets

上传素材

原始字节上传，按 sha256 落盘与寻址，天然去重。重复上传同一内容不重复计费。

参数类型说明
X-Filenameheader用于推断扩展名；非法扩展名会退化为 .bin
bodybinary原始字节，上限 RENDERD_MAX_UPLOAD_MB（默认 512）

响应

201 Created
{"asset_id": "asset_8f3d9d13546e", "sha256": "8f3d...",
 "uri": "upload:8f3d....mp4", "bytes": 5033074, "deduplicated": false}

可能的错误：E_UPLOAD_TOO_LARGE E_QUOTA_STORAGE_EXCEEDED E_INPUT_UNREADABLE

GET/v1/assets

素材列表

本租户引用的素材与占用。`charged_bytes=0` 表示命中去重：文件是别人写的，不收你的配额，但引用关系保留（否则对方删除会误删你在用的内容）。

参数类型说明
limitint，默认 100上限 500

响应

{"assets": [{"asset_id": "asset_8f3d9d13546e", "sha256": "8f3d...",
   "bytes": 5033074, "charged_bytes": 5033074,
   "created_at": 1794192694.1, "last_seen": 1794192694.1}],
 "count": 1, "storage_used_bytes": 5033074, "storage_quota_bytes": 2147483648}
DELETE/v1/assets/([A-Za-z0-9_.-]+)

删除素材（释放配额）

解除本租户对素材的引用；最后一个引用消失时才删文件并退回配额。仍被 `accepted/running` 任务引用时拒绝。

参数类型说明
asset_idpath`asset_<sha12>` 或完整 sha256 前缀；匹配多个返回 409

响应

{"asset_id": "asset_8f3d9d13546e", "sha256": "8f3d...",
 "refunded_bytes": 5033074, "file_removed": true,
 "storage_used_bytes": 0}

可能的错误：E_NOT_FOUND E_ASSET_IN_USE E_ASSET_AMBIGUOUS

阶段流水

逐条事件：阶段、时间、消息，以及编译命令、缓存键、失败原因等细节。排障先看这里。

证据回执

参数类型说明
idpathjob_id

响应

 "L0_ingest": {"actions": ["TONEMAP_HDR"], "note": "预览级 tone mapping"},

05文件

GET/v1/jobs/([A-Za-z0-9_]+)/video

下载成片

两种方式：`Authorization: Bearer <token>`，或签名 URL（`exp` / `sig` / `t`）。签名绑定租户与用途，换 `t=`、改 job_id、拿成片签名取证据文件都会 401。

参数类型说明
idpathjob_id
expqueryunix 秒，过期时间
sigqueryHMAC-SHA256(secret, JSON(["v2",tenant,scope,job_id,exp]))[:32]
tquery租户名，必须与任务 owner 一致

响应

200 OK, Content-Type: video/mp4（整文件下载，未实现 Range；需要断点续传请用 delivery.put_url 直传对象存储）

可能的错误：E_AUTH_REQUIRED E_NOT_FOUND

GET/v1/jobs/([A-Za-z0-9_]+)/evidence/([A-Za-z0-9_.-]+)

下载证据文件

`scope` 是 `evidence:<文件名>`。成片签名不能用来取这里的文件。成功下载会写 `audit(action=download.signed)`。

参数类型说明
idpathjob_id
namepath文件名，路径穿越会被规范化丢弃

响应

200 OK, image/jpeg / image/png

可能的错误：E_AUTH_REQUIRED E_NOT_FOUND

06运维

POST/v1/jobs/([A-Za-z0-9_]+)/cancel

取消任务

仅 `accepted`（排队中）可取消。运行中的任务不支持取消 —— 需要先做进程组管理，否则自动归还 running 会造成双领。

参数类型说明
idpathjob_id

响应

{"job_id": "job_...", "status": "cancelled"}

可能的错误：E_CANCELLED E_NOT_FOUND

POST/v1/jobs/([A-Za-z0-9_]+)/replay

重放死信

把 `failed` 任务就地改回 `accepted`，重置 attempts 与错误，不新建任务。若素材已被删除，会以 `E_MEDIA_MISSING` 失败。

参数类型说明
idpathjob_id

响应

{"job_id": "job_...", "status": "accepted", "attempts": 0, "replayed": true}

可能的错误：E_NOT_FOUND

GET/v1/queue

队列视图

容量信息对所有租户开放（判断要不要错峰需要它）；`inflight_by_tenant` 是运维视图 —— 普通租户只看到自己（`scope=tenant`），`RENDERD_ADMIN_TOKENS` 才返回全量。

响应

{"depth": 12, "ready": 10, "delayed": 2, "running": 3,
 "oldest_wait_s": 8.2, "failed_24h": 1, "clock_skew_s": null,
 "inflight_by_tenant": {"acme": 3}, "scope": "tenant",
 "max_queue_depth": 2000, "max_tenant_inflight": 8}
GET/v1/dlq

死信列表

本租户 `failed` 任务，按结束时间倒序。

参数类型说明
limitint，默认 50上限 200

响应

 "qps": 5, "assets": 12, "storage_used_bytes": 5033074,
