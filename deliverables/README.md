# deliverables/ · 对外交付物与验收证据

> 这里放**已经交给用户、或用于验收留痕**的东西，不是工作目录。
> 一次性截图、探针帧、临时 mp4 一律放 `out/`（可整体删除）；这里只留需要长期引用的那一份。

## 什么可以进来

| 类型 | 例子 | 要求 |
|---|---|---|
| 报告 / 一页纸 | `落地总报告.html`、`对抗审查报告.html` | 自包含（样式内联），不依赖本地相对路径 |
| 决策记录 | `决策记录-2026-11-14.md` | 写清结论、依据、被否掉的选项 |
| 验收证据 | `uv-run/`、`science-sit-back/` | 只读；文件名带日期或轮次，能追溯到任务 |
| 样片 / 联系表 | `noodle-curve/`、`templates-test/` | 体积受控；大文件优先放 `out/` 后只留链接 |
| 可分发能力包 | `desktop-video-pipeline.zip` | 版本号或日期写进文件名 |

## 什么不要放

- `out/` 里可重跑的成片、探针帧、`gate-*.json`（删了能再生成）。
- `refs/` 里的 vendor 模板、参考片（不入库、不外传）。
- 一次性调试截图；如果验收需要，放到 `out/<slug>/evidence/`，在报告里引用路径。
- 新的二进制素材（字体 / 音频 / 图片）——素材的唯一边界是 `assets/`。
