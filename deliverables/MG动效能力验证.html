能不能做出文章里这些「动态」？

针对微信公众号文章《自媒体人的效率革命！Fotor Agent 用代码写视频，零门槛搞定 MG 动画视频》（2026-11-09，北茗 / AI 机器人茶馆）——不是回答，而是交一支可播放、可复跑、可验证的成片。

结论：能做出其中绝大部分，而且已经做出来了。文章里的「动态」实质是三类东西：纯 MG 排版动效、2.5D 数学可视化、以及 Fotor Agent 的编辑器交互界面。前两类属于画面，可以用代码逐帧渲染复现；第三类是软件产品功能，不是动效。本页附带的 32 秒样片用本工作区已有的 Skia 引擎加新写的场景代码，把前两类的五种典型效果都做了一遍，全程未调用任何生成式视频模型。

03 · 能力边界：三分类，不混为一谈

已复现 · 有实测

2D / 2.5D 动效

  • 中文文字遮罩揭示、逐字、打字机、缓动位移
  • 时间轴推进、节点涟漪、连线生长
  • 数据图表、数字读数、柱状生长
  • 等轴投影立方体、拍点驱动生长
  • 透视网格形变、程序化粒子（解析轨道）
  • 镜头擦除转场、动力学文字
  • 参数化改文案 / 配色 / 时长，改完重出片
  • MP4、静帧 PNG、逐帧 seek、逐帧确定性
可补 · 本片未做或只做近似

需要额外工程或素材

  • 真 3D：本片是 2D Canvas 上的数学投影，没有 z-buffer、遮挡、材质与光照
  • 写实素材：文章里手表产品图、吸积盘写实画面是生成式 / 实拍素材打底，本片用几何与粒子近似
  • 音频节拍检测：本片 BPM 是参数解析生成，不是 onset / 词级时间戳对齐
  • 旁白与配乐：工作区已有 edge-tts + 按句时长重排分镜的链路，本片未接
  • 4K / 1 分钟成片：规格可改，本片只做 1080p / 32s 验证
  • 贝塞尔路径动画、形变、任意 SVG 遮罩
  • Case 1 结尾「肖像拼成圆形时间轴」的拼贴未做
不是动效 · 是产品交互

编辑器本身

  • 多轨时间轴精准编辑（拖拽轨道）
  • 画布上点选 / 拖拽 MG 元素
  • 右侧参数面板实时调整
  • 框选时间段或画面区域后「引用」对话修改
  • 积分预估、工程文件导出、智能剪辑

这些是 Fotor Agent 的软件功能，用代码出片无法「做出来」；但可以用前端原型实现，属于另一个交付物。

自检抓到并修复了一个真实缺陷。第一版成片里 615 帧相邻差接近零，最长一段连续 185 帧（3.08 秒）画面完全不动，集中在 intro、token、outro 三个落版段。这不是判据误报，是 60fps 输出里塞了静帧：补上公转光点、积木浮动、漂浮光点、卡片流光、柱状脉冲和全局解析扫光后重出片，最长静止降到 0.40 秒。同时把判据从「零静止帧」改为「最长连续静止 ≤ 0.5 秒」——落版保持是 MG 的正常设计，用绝对零值当门禁本身不成立。

05 · 复跑与改稿

# 出片（在工作区 motiongit-lab/ 下执行）
node mg-kit/render.mjs --params mg-kit/params.json \
  --out mg-kit/out/mg-demo.mp4 --workers 8

# 抽任意一帧检查排版（探针，不需要重出整片）
node mg-kit/render.mjs --params mg-kit/params.json \
  --probe mg-kit/out/frames/check.png --at 15.5

# 两套自检
node mg-kit/verify.mjs
uv run --with numpy python mg-kit/verify-video.py

# 改文案 / 配色 / 节拍 / 时长：只改 params.json 与 scenes.mjs 内的常量，重跑第一条

输入只有一份 params.json（分镜时间轴、字幕、BPM）加一个 scenes.mjs（画法）。渲染器 render.mjs 沿用工作区 skia-kit 的 8-worker 分片框架；字体复用 assets/fonts/NotoSansSC-*.otf。依赖只有 Node 22、@napi-rs/canvas、FFmpeg，不需要浏览器、不需要 GPU、不需要任何 API 密钥。

06 · 诚实边界与依据

  • 复刻的是动效类型，不是文章里三条成片的逐帧像素复刻。MG 的价值在信息表达方式，不在某一支具体片子。
  • 文章内嵌的 5 段完整视频直链带鉴权参数，本次未取到；判断依据是 10 个内嵌 GIF、5 张视频封面与正文描述。若需要逐镜头比对原片，请提供可下载的视频文件或录屏。
  • 档案「照片」是半色调网点加几何剪影，不是真实图灵肖像；黑洞是 2.5D 数学投影，不是 3D 引擎渲染；手表产品镜头未复刻。
  • 节拍是 BPM 120 的参数化拍点，不是从音频里检测出来的 onset；配音、字幕词级对齐、配乐均未接入本片。
  • 本片无音轨。工作区已有 desktop-kit/tools/build-voices.py（edge-tts + ffprobe 逐句时长重排分镜）与 build-sync.py（时间轴按比例重映射 + SRT），接上即可出带旁白版本。
  • 未使用 Fotor Agent、Claude Opus 或任何生成式视频模型；也未注册或登录任何第三方服务。

07 · 下一步

如果目标是一条能发的完整视频，需要你定三件事：主题与文案、画幅（横版 16:9 / 竖版 9:16）、要不要旁白配乐。现有的五类动效原语可以直接组装成分镜，改 params.json 即可，不需要重写渲染器。如果目标是复刻 Fotor Agent 那套编辑器（多轨时间轴、画布拖拽、参数面板、框选引用），那是另一个前端工程，与「做动效」是两条不同的路径，可以另行开工。
