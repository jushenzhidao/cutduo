# SPEC.md · 结构规律（换一支歌词仍然成立的部分）

> 只写可复用规律，不写"这次做了什么"。改动记录在 git 里。

## 一、节奏

| 项 | 值 | 依据 |
|---|---|---|
| 总时长 | 33.0 s 固定 | 上游 `durationPolicy: fixed`；9 镜头的动作按这个长度排 |
| 切点 | 4.25 / 7.9 / 11.05 / 15.3 / 19.8 / 23.75 / 26.55 / 29.8 / 33 | 逐段实测，中位 3.65 s |
| 最短段 | 2.8 s（paper） | 再短铅笔线画不完 |
| 最长段 | 4.5 s（city） | 再长会显得楼群静止 |
| 转场 | 全硬切 | 转场会吃掉 0.3–0.5 s，且把情绪从"句子"打散成"片段" |
| 首尾 | 淡入 0.35 s / 淡出 0.4 s | 淡入首帧留 14% 画面，否则门禁判黑帧 |

**为什么切点跟歌词不跟动作**：歌词换句是听觉上的强拍。画面先换、字后到（歌词条在 `s-0.2` 淡入），
两拍错开 0.2 s 才不会"字和画面一起砸下来"。

## 二、情绪走向（配色不是随便挑的）

| # | 镜头 | 天空 | 语义 |
|---|---|---|---|
| 1 | street | `#FFE1B4 → #E8A159` | 暖橙午后，起点 |
| 2 | cloud | `#CBD5E1 → #7B8CA0` | 灰蓝，压下去 |
| 3 | room | `#F7F0E2 → #E2CEB2` | 米色，收回来 |
| 4 | park | `#FAD3A0 → #C87B3C` | 暖棕，开始动手 |
| 5 | city | `#A7B0BB → #59616B` | 冷灰，抽离 |
| 6 | hill | `#FCD2E0 → #D887A3` | 粉色，起飞 |
| 7 | paper | `#F8F1E4 → #E2D2B8` | 纸白，落定 |
| 8 | dusk | `#FFE0AC → #D2833F` | 金色，回暖 |
| 9 | final | `#FFE9C6 → #C9762F` | 深金，收尾 |

规律：**饱和度在 4–5 段触底，在 8–9 段回到最高**。中间两段（city / paper）是"冷-白"的呼吸位，
没有它们，粉色山坡会显得廉价。

## 三、三类文字的排版数值（实测，不是估值）

| 层 | 字号 | 位置 | 其他 |
|---|---|---|---|
| 歌词条 | 62 px 楷体 | 基线在 `H-96` | 字距 6 px；双层投影 `blur 18 / offsetY 5` |
| 关键词 | 140–170 px 快乐体 | 居中，`y = 120–140` | 10 层 `1..10px` 实心偏移 + 4 px 描边；回弹 0.5 s，摆动 ±1.6° |
| 纸条 | 40 px 楷体 | 默认 `(130, 200)` | 内边距 30/22；投影 `blur 26 / offsetY 10`；旋转默认 −6° |

容量（超出必压人）：

- 歌词 62 px + 6 字距下，单行 **26 字**是硬上限（12 字 ≈ 816 px）；语义上一条 ≤14 字。
- 关键词 150 px 时 **3 字 ≈ 480 px**，4 字勉强，5 字一定压到人物。
- 纸条 40 px，一行 **6 字**；两行是默认形态。

## 四、人物

- 比例：头半径 110，脚底到头顶 ≈ 530（缩放 1 时）。**头占身高 38%**，低于 30% 就不"chibi"了。
- 骨骼：肩 → 肘 → 腕两骨 IK，上臂 104 / 前臂 98；手是半径 16 的圆 + 5 px 描边。
- 层次规则：**手举过 `y < -380` 时，手臂画在头之前（被头挡住）**，否则会横穿脸颊。
- 呼吸：`bob = sin(2.05t)*2.4`，摆身 `±1.0°`；眨眼周期 3.6 s，用纵向缩放而不是换形状。

## 五、镜头语言

- 每个镜头都有**缓慢推镜** 1.00 → 1.045（5 % 以内），焦点在人物胸口；没有它，硬切之间像两张静态图。
- 前景 / 中景 / 人物三层，前景（草、纸团、雨）画在人物之前，负责"镜头在动"的错觉。
- 颗粒 `grain` 用固定 seed：静态噪点，**不能用每帧随机**，否则整片在"闪"。

## 六、容量与时长换算

```
镜头数 = 9（固定）
每段秒数 ≈ 歌词句数 × 1.2  (本片 8 句 / 33 s ≈ 4.1 s，实际按语义分配 2.8–4.5)
```

内容超了怎么办：**减句，不缩字号**。9 个镜头各 3.65 s 是下限，靠压缩时长换内容会让动作没做完就切走。
