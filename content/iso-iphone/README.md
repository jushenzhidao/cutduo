## 这支片证明了什么

**换产品只改 JSON，不动代码**：两支片共用 `kits/iso/`，差异全在 `params.json` 的
`layers / parts / arrays / hero / mech` 与 9 拍分镜。

## 与真机的差异（如实说）

- 分层是**示意**：真机的相机、振动、主板是并排在厚度方向上的，这里为了"逐层炸开"排成 6 个 z 段；
  各层厚度按 8.25 mm 总厚等比压缩（屏幕 0.55 / 相机 2.0 / 电池 2.3 …）。
- 零件数 36 件，真机是数百件；`参数法` 不追零件级还原，追"结构关系可读"。
- 相机凸包、天线注塑条、螺丝没做。

## 几何约定

- 坐标系 x 向右、y 朝手机顶部、z 向上，单位 mm；`bounds` 就是整机外包。
- 零件不许互穿：中框（4 段）是包住内部件的环，内部件一律收在 `|x| ≤ 67 / |y| ≤ 31` 以内。
- 屏幕是"关机状态"的黑玻璃；镜片用「镜筒 + 蓝色镜片玻璃」两件，拆解时一起抬（同 hero 序号）。
