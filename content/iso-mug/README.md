## 这张图逼出来的三样引擎能力

原引擎只有"轴对齐凸块"（box / cyl / prism），做不出马克杯。这次补了：

1. **`rot`（欧拉旋转）**：任何零件可绕自身包围盒中心转。把手环、上翘的鸭喙都要它。
   代价是 AABB 变松（转 45° 的方块大 √2 倍），遮挡排序偏保守——多判几次"分离"而已，不致命。
2. **`ring`（环 / 筒）**：内径 + 外径 + 切片数。杯壁、口沿、圈足、把手都是它。
   一个 ring 零件生成 seg 个弯曲多边形棱柱；内弧面法线朝轴心，背面剔除后从杯口能看见内壁。
3. **`ball`（椭球）**：经纬细分。鸭头、鸭身、眼睛、尾巴。
   法线用归一化位置（真椭球法线是 x/rx²，这里够用且不出 NaN），两极退化成三角，Newell 法线仍有效。

另外两样是内容侧的：

- **`content.faceSort`**：所有面混排，不做零件级拓扑。杯壁**包着**鸭子时，任何 AABB 都判断不出遮挡关系
  （完整包含 → 三轴全重叠 → 拓扑建不出边），只有面级深度排得对。代价是同层大板压小件的翻面风险，
  所以只在内容本身是"有机体/环"时开。
- **`look: 'studio'`**：浅米灰墙 + 木桌 + 连续光照。白瓷在棚里几乎无对比（受光面 #f7f5f1、暗面 #d5d2cb，差 14%），
  按深色版那套 4 档量化会变成灰塑料——所以 studio 走 `f = 0.80 + 0.25·lam` 的连续映射，
  并且光照方向改成"从左上前方"（默认 LIGHT 的 +y 分量让正面变背光）。

## 如实说

- 鸭子是**低多边形近似**：球 + 扁喙 + 两颗眼。正面 3/4 角度像橡皮鸭，正对镜头时像 emoji。
  原图只有头露出，所以特写改成"整只鸭的层镜头"，避开单拍一个头的粗糙。
- 分层是**示意**：84 × 96 mm 的杯子里塞不下 7 层，这里按装配顺序切 z 段（口沿 5 / 上壁 43 / 下壁 43）,
  爆开后再拉间距。杯壁本身是**一整圈**，不分瓣——真正的剖面（cutaway）需要径向通道，引擎还没有。
- 把手是"环形把手"（O 形 + 两个连接块），原图是 D 形（直边贴壁）。ring 只能做整圈，
  要做 D 形得再加"扇环 + 直段"的拼法。
