# PB-1 · 一块移动电源的结构

等轴测爆炸图示范片：7 层 / 40 件 / 27.3s / 1920×1080@60，无声。

- `params.json` —— 全部内容：产品几何（部件、层、阵列、核心件、机构）+ 9 拍分镜。
- `make.sh` —— 渲染 + 门禁 + 节奏体检。

```bash
bash content/iso-powerbank/make.sh
```

几何全部是声明式 JSON，**改产品不改代码**：换尺寸只改 `parts` 与 `bounds`/`radius`，
换层数改 `layers`（爆炸行程按层数自动算），换配色改 `materials`。
零件之间不许穿插——互穿会让画家算法的遮挡顺序无解，画面上就是随机破面。
