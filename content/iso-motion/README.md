# 转场与循环（运动研究）

13.6s / 816 帧 / 1920×1080@60，用 iPhone 的几何跑四种运动，专门看"怎么进下一个镜头"。

| 段落 | 时间 | 运动 | 做法 |
|---|---|---|---|
| 1 | 0–2.6 | 亮相 | 慢推 0.94 → 1.08 |
| 2 | 2.6–5.2 | **ORBIT** | 绕到目标机位：中点抬高 + 侧绕 20° + 荷兰角 10° + 变焦压到 0.84 |
| 3 | 5.2–7.8 | **SPIN** | 原地转 360°（0.52 s，正弦缓动），终点与起点同向 ⇒ 衔接无缝 |
| 4 | 7.8–11.0 | **LOOP** | 循环自转：正弦摆动 ±30°、roll ±4°，段首段尾完全相同 ⇒ 可直接当循环素材 |
| 5 | 11.0–13.6 | WHIP | 普通甩镜收尾 |

## 运动模糊

转场期间（`plan` 给出的 blur 窗口）每个子帧先画到离屏画布，再按 1/N 加性叠到累加图，
最后整张贴回。8 个子帧、快门 0.8 帧。

三个坑（都踩过）：
1. 直接在主画布叠半透明残影 ⇒ 深色产品上只有"重影边"，看不出模糊。
2. 在一张离屏图上直接叠子帧 ⇒ 同一子帧里多个面也会相加，中心过曝成白块。
3. spin 用五次方缓动 ⇒ 峰值速度 5× 平均，360° 变成每帧 46°、只剩频闪。改正弦缓动（峰值 1.57×）。

```bash
node render.mjs --kit iso --params content/iso-motion/params.json --out out/iso-motion.mp4
# 或看橙色版：ISO_LOOK=split
```
