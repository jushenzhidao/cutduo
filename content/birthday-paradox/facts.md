复算方法（Python，标准库即可）：

```python
from math import comb
def p(n, d=365):
    q = 1.0
    for k in range(n): q *= (d - k) / d
    return 1 - q
p(23)   # 0.5072972343239857
p(41)   # 0.9031515722488756
p(57)   # 0.9901224593411699
comb(23, 2)   # 253
```
