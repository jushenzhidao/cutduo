### 实测结论（可复用）

1. **这类片子的结构是"信息卡片序列"，不是动画叙事**。48 个切点的归类：
   讲解位 18（37%）/ 图解释意 16（33%）/ 标签强调 5（10%）/ 阵列 3（6%）/
   对比 2（4%）/ 首尾 2（4%）/ 场景 1（2%）。
   ⇒ 科普模板的交付物应是「8 类信息版式 + 标签语汇 + 字幕轨」，不是角色动画系统。
2. **切点中位 2.75s**（min 0.75 / max 6.25 / 均值 3.03），跟着句子走不跟动作走。
   开场密、中段稳、收尾慢。
3. **配色规律**：背景永远低饱和（米白 #F8FAE7 / 青绿 #C6E5E3 / 天蓝 #7DCEE5），
   高饱和只给标签（#FD2551 爆炸贴、#FFD84D 标签黄、#26A38C 标题条、#2B7FD4 蓝边）。
4. **字幕是主信息通道**：白字 + 深色粗描边、无底衬、34px@960（≈62px@1080）、
   单行 8–14 字。画面标签 100px : 字幕 33px ≈ 3:1 的字号分级。

### 工程踩坑（写进模板注释了）

- **`env.T` 必须是"完整调色板 + theme 覆盖"**。只传 theme 会让 `T.white` 等变 undefined，
  canvas 的 `color: undefined` 会沿用上一个 fillStyle ⇒ 文字变墨色、横条变灰。这个 bug 排查了两轮。
- **`MK.icon` 内部会按 (x±size/2) 平移**。若外层已 translate 到中心，再传 cx/cy 会二次偏移，
  器官直接飞出画面（曾画到右下角）。
- **硬切片的段首必须不空**：入场动画一律从 `-0.1s` 起，容器类元素用
  `enter(v, from)` 从 0.86 收到 1（不要从 0 pop），否则切点第一帧是"缩成一点"。
- **macOS 无 Yuanti SC / 圆体**（系统字体里只有 Hiragino Sans GB、STHeiti、PingFang）。
  卡通胖标题靠「同色描边膨胀」`heavy = size × 0.05` 补，不要指望 900 字重。
- 底部 940px 以下设为字幕禁区；角标上移到 `H-238`，否则会被居中的长字幕压住。

### 抓到并修掉的真 bug：`heavy` 同色描边把密集汉字糊成实心块

- 现象：手写红字「能**量**只够让分子发热」里的「量」渲染成一块橙色矩形。
- 最小复现：`strokeText(白 13.3px)` + `strokeText(同色 3.9px)` + `fillText`，「量」必糊；
  只做白描边不糊。根因是 78px 下「量」的横缝只有 ~4px，同色描边 ≥3px 就把缝填满。
- 实测安全阈值：**同色描边 ≤ 2.2px**（A/B/C/D/E/F 六组对照，3.9 糊、2.2 与 1.7 均清晰）。
- 修法：`heavy = min(size × 0.05, 2.2)`；`handText` 白边 `0.17×size → 0.12×size`。
- **所有带中文大标题的 canvas 模板都会踩这个坑**，不是本模板特有。

### 另一个坑：`probe: "none"` 是 truthy

`if (a.probe)` 判断字符串，传 `"none"` 反而会画出探头。已改为 `if (a.probe && a.probe !== 'none')`。
参数枚举里凡是 "none"/"off" 之类的字面量，都要按 truthy 处理。

## 补配音：`tools/vo.py`（配音驱动时间轴）

用户问「为啥没有音频」——**是我漏了**。motion-render 的 `--audio` 只做 mux，不生成语音。

### 原则：时间轴跟随配音，不是配音迁就时间轴

- 脚本先定 50s 再塞 TTS，必然对不上（只能变速或砍字）。
- 参考片的节奏本来就是口播决定的：中位镜头 2.75s ≈ 一句话。
- 流程：逐句 edge-tts 实测时长 → 段长 = 首留白 0.45 + 本段语音 + 句隔 0.28 + 尾留白 0.55
  → 句子写进全长静音底 → -16 LUFS → 写回 `*.vo.json`。
- 实测：微波炉 50s → **64.8s**；医学版 54.5s → **73.8s**。

### 顺带修的三件事

1. **`tip` 长镜头静止**：一张便签 10.5s 全程不动。现在 `vo.py` 自动写 `args.itemAt`
   （第 i 句 → 第 i 条点亮），便签逐条点亮、其余压暗。
2. **音频尾短 1 帧**：`-shortest` 会截掉视频最后一帧（1944/1945）。vo.py 尾部多写 0.12s 静音。
3. **响度**：edge-tts 原始约 -21 dB，loudnorm 到 I=-16 / TP=-1.5。

### 音色

`zh-CN-XiaoxiaoNeural`（Warm，女）+ rate +8%。男声可换 `YunxiNeural`（阳光）/`YunyangNeural`（新闻腔）。
