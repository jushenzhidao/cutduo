## BGM 重做（用户反馈"不咋地"）

- 诊断：`add-bgm` 用 8.3s 的 Mellow Drizzle Soft Pad，105s 里循环 12 遍 ⇒ 必然单调。
  Apple Loops 全是短 loop（最长 Wonderland Pizzicato Strings 28.7s），**换曲解决不了重复**。
- 做法：`content/birthday-paradox/bgm.py` **分层配乐**，按 params.json 的段落边界让各层进出：
  A 拨弦（28.7s）全程 / B 极简后拍（4s）@20.35s 起 / C 张力低音（7.5s）@69.61s 起。
  电平包络用 ffmpeg `volume='if(lt(t,..),..)':eval=frame`，首尾 fade。
- **顺带抓到一个潜伏 bug**：`src/audio-mix.mjs` 的 ducking 把 `[voice]` 同时用于
  `sidechaincompress` 和 `amix`，**没 asplit** ⇒ 第二路拿空 pad，**旁白从成片里消失**。
  实测 105s 片混完 −21.0 LUFS（比旁白 −16.9 还低）。修 `[voice]asplit=2[voiceKey][voiceMix]`
  ⇒ −16.6 LUFS 正常。加 `MIX_DEBUG=1` 打印 filter graph 便于排查。
- 结果：v2 = 6339 帧 / −16.6 LUFS / gate PASS（含 --require-bgm）；RMS 标准差 12.48 vs 旧版 8.13。

## 配乐 v3：更电子（用户第二次反馈）

- **BPM 判据**：Apple Loops 没有 tempo 元数据，靠时长推 —— `7.5s` 与 `3.75s` 是二倍关系 ⇒ 同为
  **128 BPM**（同属 02 Electro House）。Chillwave 的 `12s` loop 是另一个速度，**混进来会听觉错位，不能用**。
  跨系列拼配乐前先看时长能否整除，这比听更可靠。
- v3 四层全取自 02 Electro House：Binary System Synth Layers（全程）/ Blueprint Beat 01（量化段起）/

  窗口包络用嵌套 `if(lt(t,..))`，可以表达"只在某段出现"而不只是"从某点开始"。
- 结果：v3 = 6339 帧 / **−16.8 LUFS** / gate PASS。三版动态：final 8.13 → v2 12.48 → v3 11.57（标准差）。
- 教训：**电子乐靠重复建立节奏，短 loop 不是缺陷**；上一版（抒情 pad）短 loop 才是问题。
  换曲前先判断曲风是否依赖 loop 循环。

## 时间轴契约的收益对比（三个实验）

- 产出：`docs/时间轴-收益对比-2026-11-14.md`；注入样本 `out/temporal-ab/`。
- **实验一（故障注入，核心）**：拿已过全门禁的生日悖论 v3 注入 5 类错误 ——
  倒序 / durationSeconds 减 10s / 重叠 3 帧 / 离帧 0.4 / 空隙 1.5s。
  **temporal 拦下 3/3 会导致成片错误的；gate 全部 PASS**。因为 gate 只看成片像素，不看 params。
- **像素证据**：倒序版与基线逐帧比 —— 6339 帧里 **908 帧（15.1s）PSNR<40dB**，区间 20.4–35.5s
  正是被注入的 scenes[2]；其余 5431 帧完全一致。**15 秒画面错了，门禁判 PASS。**
- **实验二（累加漂移）**：按秒分配 9/29/100/300 段 → 漂 0/−2/+2/−8 帧；按帧分配**恒为 0**。
- **实验三（改一句旁白）**：生日悖论共 98 个时间数字；第 4 段变长 2s，手写要同步 **50 个数字**，
  声明式只改 **1 个 for**。漏改一个就是实验一的某类错误，而 gate 发现不了。
- 局限（写进报告）：默认只告警不拦（存量有 3 个骨架）；只管时间结构不管内容；
  声明式收益目前是理论值（存量 87 params 仍手写）；不能替代看片。
- **一个注入设计的教训**：第一次注入"重叠 1 帧"没被检出，查下去发现**场景之间本来就有 0.25s 拍间隔**，
  减 1 帧只是把空隙从 15 帧变 14 帧 —— 是注入错了，不是校验器漏了。造错误也要先看数据。
