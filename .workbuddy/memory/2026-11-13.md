## 00:51 · 命名改为速度档优先（用户第二次反馈后）

用户：「还是看不懂，应该用技术栈命名？」→「或者按速度效率也行」。

**放弃雅名**（桌面线/纸感线/杂志线）——对工程师多一跳记忆负担，且我上一版把 editorial
误说成浏览器 canvas2d（实际用 `@napi-rs/canvas`，全仓只有 `motion-render.mjs` 用 playwright）。

**定稿**：`速度档 / 模板 / 传帧 / 封装`，例 `极速档 / desk / raw / h264`。
- 极速档 `fast` 344 fps（Skia + GPU 壁纸 + 裸帧，同片 68.8s → 12.0s）
- 标准档 `std` 189–210 fps（Skia + 静态壁纸 + 压缩帧）
- 浏览器档 `chrome` 55 fps（film-kit 官方）
- 对照档 `ref` 24.6 fps（cinecode）
- 速度只由两个开关决定：有无浏览器（6×）、中间帧压缩（10–30%）；其余 <5%。
- **fps 随片长上升，比较必须同片**（4127 帧 344 vs 1419 帧 195–210）。
