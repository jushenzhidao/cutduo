## 商业化剪辑能力技术选型 —— 第一性原理落地评审

**输入**：用户提供的《商业化剪辑能力技术选型方案.md》（MLT 时间线引擎 + FFmpeg hwaccel + WebCodecs，Agent-First MCP）。
**诉求**：用第一性原理解决落地；后追加「结合 BSK（腾讯开源浏览器 skill）」。

**核心结论（已写入交付文档）**
1. 渲染层已商品化：阿里云 IMS 1080P 剪辑 ¥0.06/分钟；自算直接成本 ≈¥0.049/分钟（算力 31% / 出口带宽 61%），按分钟卖毛利仅 ~18%。→ 计量单位必须改为「条 / 席位」，不可按分钟。
2. 原方案两处设计假设不成立：
   - 「MLT XML 是唯一事实来源」→ 改为自有 IR 为事实来源，MLT XML 降级为编译产物（缓存键 = hash(IR+引擎版本+字体集+输出规格)）。
   - 「双端差异 ≤1 帧」→ 实测证明该指标既不可达又过宽松；改为 L1 结构 / L2 感知（仅回归）/ L3 语义三层合约。
3. BSK（Tencent/BrowserSkill, MIT）应作为 Ingest 与 Distribute 两端，而非渲染层。因阿里云 IMS 要求素材已在 OSS，而客户素材散落在内部系统 —— 迁移摩擦才是真痛点。

**实测数据（cutproof/，Apple Silicon / ffmpeg 9.0.2 / 1080×1920×450f）**
| 断言 | L1全等 | SSIM | PSNR | VMAF | 字节同 |
|---|---|---|---|---|---|
| M1 同后端两次 | ✓ | 1.00000 | ∞ | 99.30 | ✓ |
| M2 软编 vs 硬编 | ✓ | 0.99435 | 43.41 | 97.06 | ✗ |
| M3 时间线偏移1帧 | ✓ | 0.96076 | 25.41 | 72.91 | ✗ |
| M4 字体缺失错片 | ✓ | 0.97970 | 24.26 | 39.00 | ✗ |

关键洞察：L1 结构层对错片无鉴别力；SSIM 会被小面积高对比错误骗过；VMAF 需 reference 故只能做回归不能做首次验收。

**产出文件**
- `deliverables/剪辑能力落地-第一性原理重算.html`（主报告，8 节）
- `cutproof/`：可重跑 harness（IR schema + 双后端编译器 + 三层断言 + receipt）
- `cutproof/README.md`：用法与三个不可逆决定

**环境备注**：本机 brew 无 melt 运行时，MLT 分支仅做结构校验；本机 ffmpeg 9.0.2 未编译 freetype（无 drawtext），文字层改用 Pillow 栅格化成 RGBA 图层再 overlay —— 这反而更符合确定性设计要求。本机无 PingFang.ttc，中文字体用 Hiragino Sans GB。

## P0 阶段落地（同日，用户要求「全部落地后再审查」）

**新增交付**

- `cutproof/corpus/gen_dirty.py`：21 条故障语料工厂，**生成后自校验故障特征是否真复现**（对不上即 INEXPECT 非零退出）
- `cutproof/ingest.py`：probe（只观测）/ decide（只决策，输出声明式动作+错误码）/ normalize（只执行+8 项规格自校验）
- `cutproof/asserts.py`：L3 断言库（notdef 指纹法查字形覆盖、安全区、响度、黑场）+ receipt
- `cutproof/mcp/tools.json`：5 个 Agent 工具 + receipt schema + 错误语义
- `cutproof/P1-启动包.md`：BSK 取材 runbook / GPU 规格 / 定价速算 / 门禁
- `cutproof/ci/gate.sh`：五步门禁，第 5 步是**负向测试**（字体缺失错片必须被拦）

**实测统计**：21 条语料 → 1 条零转码直通、17 条转码通过校验、15 条带警告、3 条硬失败（E_INPUT_UNREADABLE / E_INPUT_AUDIO_ONLY / E_INPUT_TRUNCATED）。

**三个跑出来才发现的坑（已写入手册）**
1. libx264 单给 `-color_primaries` 不写 SPS VUI，必须 `-x264-params colorprim=bt709:transfer=bt709:colormatrix=bt709:range=tv`，否则 ffprobe 读到 unknown。
2. 奇数分辨率偶数化必须 `crop` 不能 `scale`（scale 是整幅变形，crop 是丢 1px）。
3. ffmpeg 9 已不支持 `-metadata:s:v rotate=90` 写显示矩阵，须 `-display_rotation 90 -c copy` 两步。

**BSK 澄清**：bsk = Tencent/BrowserSkill（MIT），bsk CLI + 本地 daemon(127.0.0.1 WS) + Chrome/Edge 扩展，借用户已登录 profile 在独立 Agent Window 操作，支持 request-help 人工接管、0.3.x 有远程配对与操作审计。定位：Ingest（素材在客户内部系统，不在我们 OSS）与 Distribute（多平台投递+人工确认）两端，不是渲染层。因 MV3 禁止远程代码 + SW 不能起 Worker，自研插件不划算。
