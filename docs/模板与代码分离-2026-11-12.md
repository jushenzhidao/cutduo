# 模板（内容）与代码分离 · 2026-11-12

## 一、为什么分

原结构里，**渲染器代码**与**每支片的分镜/文案**同住 `desktop-kit/`：

```
desktop-kit/
├── desktop.mjs       渲染器（代码）
├── render.mjs        CLI（代码）
├── verify.mjs        自检（代码）
├── tools/            工具（代码）
└── presets/          15 个 JSON（内容）  ← 与代码混在一起
```

后果是改一句文案要进代码目录，代码评审时也会混入内容改动。`.motion` 包内也有 `presets/`（模板样式分支），名字相同但语义不同，容易误伤。

## 二、怎么分

| 层 | 位置 | 说明 |
|---|---|---|
| 代码 | `desktop-kit/`（`desktop.mjs` / `render.mjs` / `verify.mjs` / `tools/`） | 只放渲染与工具，不再含分镜 |
| 内容 | `motiongit-lab/content/` | 15 个分镜 JSON（6 支片 × nominal/voiced，另加 cmp/md） |
| 素材 | `motiongit-lab/edits/assets/` | 实拍照片、生成人像、Pexels 图与视频帧 |
| 产物 | `motiongit-lab/out/` | 成片、总览、报告（已忽略入库） |
| 第三方模板 | `motiongit-lab/templates/` | 下载包与自建模板，含个人 Key 的已排除 |

命令调用方式不变，只是路径前缀从 `desktop-kit/presets/` 换成 `content/`：

```bash
node desktop-kit/render.mjs --params content/hotpot.json
uv run python desktop-kit/tools/build-voices.py --preset content/hotpot.json
```

保留 `desktop-kit/presets -> ../content` 的**过渡软链**，让历史命令、旧文档与已安装的 skill 不会立刻失效；下个大版本可删。

## 五、一处必须记录的失误（上一轮清理的遗留）

上一轮「体积清理」删掉了 `ref/mac-desktop/frames/`（29 张参考抽帧），但 `verify.mjs` 依赖其中
`t104.jpg` 做骨架几何标定，导致自检从 13/13 掉到 **12/13（参考帧存在 FAIL）**。
本轮已从仍在的 `ref/mac-desktop/demo.mp4` 用 `ffmpeg -ss 104` 重抽该帧，保存到 `ref/mac-desktop/t104.jpg`（与已入库的 `t60.jpg` 同级，**随仓入库**，避免换机器后自检再次 FAIL），几何断言 PASS，恢复 13/13。

**教训**：删参考帧/校准素材前，先 `grep` 自检与门禁脚本对它的依赖；「可重建」不等于「删了不影响门禁」。
