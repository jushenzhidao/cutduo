## 1. 六镜结构

外层是剪辑意义的六镜（SCATTER→GATHER→RECALL→ARRANGE→ROUTE→LOCKUP），
内层是产品意义的四功能（01 SAVE A PLACE / 02 RECALL / 03 / 04 YOUR ROUTE）。
**两套编号错开一位**：外层第 2 镜讲的是内层第 1 个功能。这不是笔误，是刻意的双轨——
观众同时感知"这是一支被剪出来的片"和"这是一个有四个能力的产品"。

| # | 章节名 | 起止 | 时长 | 底色 | 内层号 | 构图 |
|---|---|---|---|---|---|---|
| 01 | SCATTER | 0.000–2.533 | 2.53s | 近黑 | — | 空间散布：真 UI 卡片随机朝向漂浮，强景深 + 拖影 |
| 02 | GATHER | 2.533–≈4.9 | ≈2.4s | 白 | 01 · SAVE A PLACE | 左文右卡：左侧衬线大标题 + CTA，右侧 7 张卡堆叠 |
| 03 | RECALL | ≈4.9–≈7.1 | ≈2.2s | 白 | 02 · RECALL | 居中单栏：标题 + 搜索框 + 全宽结果列表（底部渐隐） |
| 04 | ARRANGE | ≈7.1–9.633 | ≈2.5s | 白 | （被 AI 浮层替代） | 居中单卡 + 标签径向发散 + 虚线连接 |
| 05 | ROUTE | 9.633–12.300 | 2.67s | 近黑 | 04 · YOUR ROUTE | 深色纵深：文字层叠回声 + 玻璃卡片 + 手绘曲线 |

### 每镜的构图轴各不相同

这是全片最值得学的一条：**六镜用了六种信息轴**，没有一个模板被复用两次。

| 镜 | 信息轴 | 眼神动线 |

| SCATTER | 纵深（Z） | 从画面深处往前推 |

| RECALL | 纵向单栏 | 上→下 |
| ARRANGE | 径向（中心卡 → 四周标签） | 中心→外 |
| ROUTE | 纵深 + 斜向 | 沿曲线走 |

## 2. 可平移的九条

### 2.1 制片监视器 HUD 常驻（本仓完全没有的一层）

四角各一件，加底部一条轨道：

| 位置 | 内容 | 样式 |
|---|---|---|
| 左上 | `<品牌> · MOTION SHOWREEL` | 灰 ≈#9A9A9A，全大写，字距 +0.08em，约 20px |
| 右上 | `NN / 06 · CHAPTER` | 等宽，`NN` 更亮、`/ 06` 中灰、章节名深灰 |
| 左下 | 时间码 `00:00:MM:FF` | 等宽，**30fps 非丢帧**（FF 01–30，从不出现 00） |
| 右下 | `1920x1080 · 30 FPS` | 等宽，最小的字级（约 16px） |
| 四角 | L 型角标 | 长约 21px、1px 线、约 25% 不透明 |
| 底部 | 全宽进度轨 + 淡刻度 + 播放头 | 左端到右端各留 40px（2.1% 宽）；已过段深、未过段浅 |

**作用不是装饰，是"可信度声明"**：HUD 让观众默认这支片是被剪出来的素材，
而不是被 AI 生成的广告。本片把这条用到了极致——**最后 2.7 秒的品牌落版上 HUD 仍在**
（时间码继续走到 00:00:14:09），等于说"这支片本身就是我们的作品"。

不透明度全程约 55–70%，永不与主体抢对比度。这一层是**纯叠加**，不改内容，
所以它是全片唯一能脱离素材独立移植的特征 → 落地为 `tools/hud-overlay.mjs`。

### 2.2 叙事字衬线 / UI 字无衬线的二分

`Save it. / Go places.` 是高对比 Didone 衬线；卡片里的 `Kyoto, slowly`、
`Six stops, three days` 全是无衬线。

这不是字体搭配，是**层级编码**：衬线 = 作者在说话，无衬线 = 界面在说话。
观众不需要读文案就能分出"哪句是旁白、哪句是产品里的字"。

本仓现状：全仓只有 Noto Sans SC / Mona Sans / JetBrains Mono 三系（加文楷、粉笔两把特例），
**没有这个二分**。要落地必须先加字体，见 §3。

### 2.3 双色标题：只染后半句，且强调色随底色极性换

- `Save it.`（黑）+ `Go places.`（蓝 #2F3BE8）
- `Just ask.`（黑）+ `Find it.`（蓝）
- `Turn your ideas`（黑）+ `into journeys.`（蓝）
- `Connect the dots.`（白 + 青绿 #3FD9A0 回声）← **深色段换青绿，不延用蓝**

规则：染色部分 ≤ 全句 45%，一个画面只有一个强调色；浅底用蓝、深底用青绿。
颜色不是"品牌色固定"，是"随底色的对比度选择"。

### 2.4 单叙事道具贯穿全部功能段

四段演示全在同一条行程上：存下京都 → 搜 `seaside town` 出镰仓 → 打标签编排 → 连线成路线。
连元信息都自洽（`Trip card · Saved Wednesday`、`3 friends synced`、`97% match`）。

本仓习惯是"每段换一个例子"，代价是观众记住四个例子、记不住一件事。
这条的迁移成本几乎为零，只需要**写文案时强制一条主线**。

### 2.5 卡片是"真 UI 截图"，且每张带类型药丸

七张卡：`Place` / `Note` / `Photo` / `Ticket` / `Route` / 音频条 / 统计条。
每张左上角有一个**实色小药丸标类型**（圆角、白字、约 6px 字高），颜色按类型分（蓝 / 青绿）。

排布：旋转 −3°~+3°、尺寸不等（最大卡占宽 11%、最小 6%）、部分重叠、统一柔和投影。

截图本身搬不了（版权 + 内容不匹配），但**类型药丸**可以：每张卡一个 20 行的角标，
成本极低，辨识度提升明显。这条是本片"每张卡都像真东西"的一半原因。

### 2.6 置信度用饱和度分级，不改尺寸

结果列表里 `97% match` 是蓝底白字（实色），`84% match` 是浅灰底灰字。
同一字段、同一尺寸、同一位置，只靠**填充饱和度**区分强弱。

适用于本仓所有"数据条 / 排名 / 热度"段型，比改字号或加粗更安静。

### 2.7 eyebrow 三件套

`NN · PHRASE`（全大写、字距 +0.1em、强调色、约 23px）
+ 下方 2px 短横线（宽 = 文字宽的 40%）
+ 与主标题间距 = 主字号 × 1.8。

三段一致（01 · SAVE A PLACE / 02 · RECALL / 04 · YOUR ROUTE），是段落切换的锚点。
ARRANGE 段的 eyebrow 位被 `✦ AI is connecting your trip..` 替代——
**用产品语气替掉章节标签**，这一手比换个图标高明。

### 2.8 底部渐隐遮罩 = "还有更多"

列表第三行被纵向渐变切掉。一个 `linearGradient` 的成本，解决了"列表看起来完了"的问题。

### 2.9 落版公式

`logo 方块`（圆角 + 曲线路径 + 强调色点）
+ 品牌衬线大字（`Dreamina`，约 96px）
+ 次行小字（`Motion Studio`，约 28px，灰）
+ slogan（后半句染色）
+ 强调色胶囊 CTA（`Start planning →`）
+ 平台清单（`iOS · Android · Web · WeChat · Browser`，`·` 分隔，最小字级）

六件套，缺一件就不像"官方落版"。

## 4. 对抗审查

1. **假阳性**：如果把 HUD 做成检查器，本仓现有十支成片**全部 FAIL**（一支都没有 HUD）。
   → HUD 只能做**可选叠层**，不进 `src/gate.mjs`。任何"没有 HUD 就不合格"的判据都是错的。
2. **假阴性**：HUD 叠太满会遮挡主体与字幕条。工具默认 62% 不透明度、四角 24px 安全边距，
   并提供 `--at <秒>` 出单帧供人眼过——**不给"自动合格"的错觉**。
3. **自身失效**：读不到 ffprobe 时必须 `exit≠0`，不能静默出一支无 HUD 的片。
   本仓历史教训：`probe` 在各入口是 `process.exit(0)` 早退，测不到下游。
4. **口径漂移**：`110px / 96px` 是从 **1920 宽**反推的。换 1440×1080 或竖屏必须按**短边**重算，
   直接套会撑破。实测依据：主标题 cap height ≈ 原片 110px（占宽 5.7%），行高 ≈ 1.05 倍。
5. **未证实项**（不写进规则）：底部轨道上除播放头外还有 2–3 条更淡的竖刻度，
   间隔不规则（t=4.2 时在 x≈750，t=7.4 时在 x≈470/643），既不对应章节也不对应 2.5s 整点。
   可能是节拍或缓存标记，**没有足够样本，不作为规则**。

## 5. 落地：做了什么、没做什么

**做了**：`tools/hud-overlay.mjs` —— 把制片监视器叠层加到任意成片上。
零新增依赖（`@napi-rs/canvas` + 本仓 ffmpeg 管线），逐帧出 PNG 再 overlay 合成。
这是全片唯一"不改内容就能移植"的特征。

**没做 kit**：三条硬伤同时存在——缺 Didone 字体、缺 UI 截图、节奏模型与口播不兼容。
硬造一支"看起来像、读不出信息"的片，比不做更糟。等字体落地（§3 第 1 条）再评估。

**没做检查器**：HUD 是否齐全不是质量判据（§4 第 1 条），做出来只会误杀。

## 6. 验证：换成自己的素材后，这套语法成不成立

做了一支验证片：`out/jimeng-showreel.mp4`（15.000s / 450 帧 / 30fps / −16.0 LUFS，
`node src/gate.mjs` PASS）。出帧脚本 `tools/jimeng-demo.mjs`，叠层 `tools/hud-overlay.mjs`。
文案换成 cutduo 自己的一句话出片链路，不是 Dreamina 的原文。

**结论：语法成立，但有三个必须付的代价。**

### 成立的部分（六条）

1. **六镜各换信息轴** —— 纵深散布 / 左文右卡 / 纵向单栏 / 径向发散 / 深色层叠 / 中心落版。
   实践下来这是全片最值钱的一条：观众每 2.5 秒换一次"读画面的方式"，不会疲劳。
   本仓过去"一个版式贯穿"的做法在这里明显吃亏。
2. **明暗只在三处切换** —— 深(2.5s) → 浅(7.5s，横跨三镜) → 深(2.5s) → 浅(2.5s)。
   中段三镜共用一张浅底，靠内容重排分段，靠的不是切点。
3. **双色标题只染后半句** —— `写一句。` / `出成片。`、`一句话。` / `一帧不差。`、
   `一句话，` / `一条片。`。中文短句的对仗比英文更容易成立，因为字数可控。
4. **eyebrow 三件套**（`01 · WRITE` + 短横线）比预期更有用：它是唯一的"我还在原地、
   只是换了话题"的信号。
5. **类型药丸**（STORY / PARAMS / RENDER / GATE / FILM）成本 20 行，是"每张卡都像真东西"的一半原因。
   剩下的一半是**卡里的数字是真的**（450 帧 / 344 fps / 0.004s 都来自本仓实测）。
6. **单叙事道具** —— 全片只讲"一句话 → 一条片"，四张卡是同一条链路的四个环节。

### 代价（三条）

| 代价 | 具体 | 缓解 |
|---|---|---|
| **字体** | 中文没有 Didone 等价物，必须用思源宋体 Black（11 MB 单文件）。Noto Sans SC Black 渲同一句会变成海报黑体，气质完全不同 | 已下载到 `assets/fonts/`，由脚本单独注册，**不进 `src/fonts.mjs`** —— 不该让五支内置 kit 的字体表跟着变 |
| **"真 UI 截图"降级** | 原片 7 张卡是真产品截图；这里换成自绘的"真实数据卡"。可信度低一档：观众分不清真假，但至少数字不是编的 | 不伪造截图是底线；要再上一档只能接真实截图源 |
| **节奏锁死** | 2.5s/镜 + 无旁白。中文口播在这个节奏下塞不进"标题 + 副文案 + 卡片"三层 | 这套结构只适合音乐驱动片；有口播时必须拉到 ≥6s/镜 |

### 一条反直觉的实测

首版把背景（浅底 2400 个点阵 + 深底 30 条网格）逐帧重画，450 帧用了 **154s**。
改成预渲染缓存 + `drawImage` 后是 **126s**，只省 18%。
真正的瓶颈是 PNG 编码（每帧约 180ms 的 `toBuffer` + 写盘），不是绘制。
**"看起来最重的循环"往往不是瓶颈** —— 这条对以后所有逐帧渲染的优化判断都适用。

### 参数化与容量校验（2026-11-16 补）

文案与卡片数据已抽到 `content/jimeng-showreel/params.json`，`--params` 可换；
换题材只改 JSON，不改代码。判据 `tools/jimeng-demo-check.mjs`（A1–A5 + D1–D2）。

两条设计取舍值得记：

1. **重构等价的判据是"帧 md5 等于改动前的基线"，基线存盘不现算。**
   现算等于自己跟自己比，改了代码基线跟着变，永远绿。
2. **文案超宽时报错，不自动缩字号。** 实测长文案会让卡片标题穿出卡片（`一条片子做三天其实只要一天`
   需要 442px、卡内可用 288px）、大字压到玻璃卡。但字号是这套片子的设计决策——`写一句。` 和
   `往里掉，就出不来。` 必须是同一个字号，自动缩会悄悄破坏层级。所以用 `TEXT_SLOTS` 声明每个
   版位的**文字容量**，超出就拒绝并给出「建议 ≤N 字」。

### 复现

```bash
node tools/jimeng-demo.mjs                    # 450 帧 → out/jimeng-demo/
ffmpeg -framerate 30 -i out/jimeng-demo/%05d.png -i <bgm.wav> \
  -c:v libx264 -crf 17 -pix_fmt yuv420p \
  -af "loudnorm=I=-16:TP=-1.5:LRA=9,aformat=sample_fmts=fltp:sample_rates=48000:channel_layouts=stereo" \
  -c:a aac_at -b:a 160k -shortest out/jimeng-demo.mp4
node tools/hud-overlay.mjs --in out/jimeng-demo.mp4 --out out/jimeng-showreel.mp4 \
  --brand cutduo --reel "MOTION SHOWREEL" \
  --chapters "SCATTER@0,GATHER@2.5,RECALL@5,ARRANGE@7.5,ROUTE@10,LOCKUP@12.5"
```

两个坑：
- `-c:a aac_at` 在 `loudnorm` 之后会报 `AudioToolbox init error`，必须先
  `aformat=sample_fmts=fltp:sample_rates=48000:channel_layouts=stereo` 收敛采样格式。
- `@napi-rs/canvas` 的字体**没有隐式回退**：`'23px "JBMono"'` 遇到中文直接渲成豆腐块，
  必须写全 `"JBMono", "NotoSC Regular"`。`✦`（U+2726）三个字体都没有，只能用路径画。
