# 音效：earshot 配方音效接入（2026-11-14）

> 上游 `Leonxlnx/earshot`（MIT，0.4.0）：252 条音效，**不是音频文件而是配方**——纯 DSP（numpy/scipy）、无模型、无网络、无采样。
> 本仓库通过 `src/audio-mix.mjs` 的 cue `src` 字段接入，零侵入：原有的内置合成音与文件路径用法完全不变。

## 一、装（一次性）

```bash
git clone --depth 1 git@github.com:Leonxlnx/earshot.git ~/tools/earshot
cd ~/tools/earshot && uv venv --python 3.13 && uv pip install -e .
~/tools/earshot/.venv/bin/python -m earshot sfx list      # 252 sounds in the bank
```

uv 是硬规则（本项目所有 Python 环境走 uv）。装完 `src/audio-mix.mjs` 自动探测 `~/tools/earshot/.venv/bin/python`。

| 环境变量 | 作用 |
|---|---|
| `EARSHOT_PY=/path/python` | 显式指定解释器。**指定即强制**，路径不可执行就降级，不再回退探测（保证线上行为可复现） |
| `EARSHOT_PY=none` | 显式禁用，全部降级为内置合成音（跑回归、隔离部署时用） |
| `EARSHOT_CACHE=/path` | 缓存目录，默认 `~/.cache/cutduo/esfx` |

## 二、怎么写 cue

```json
{
  "at": 4.5,
  "src": "whoosh_fast/tight",
  "align": "peak",
  "lead": 0.037,
  "gainDb": -12
}
```

| 字段 | 说明 |
|---|---|
| `at` | 画面事件时刻（秒）。**唯一需要跟着时间轴走的字段** |
| `src` | 三种形态：earshot 音色 id（`category/member`，含 `/` 且两段是字母数字下划线）／内置合成音（`whoosh` `tick` `impact` `rise`）／文件路径 |
| `align` | `onset`（默认）｜`peak`｜`end`：让哪个**实测参考点**落在 `at + lead` |
| `lead` | 额外偏移（秒，负值提前）。上游实测：轻触早 60 ms、敲击早 40 ms、嗖声最响点晚 37 ms、反向镲晚 42 ms |
| `gainDb` | dB 增益（优先于 `gain`）。earshot 素材峰值 −1 dBFS，推荐 −8 ~ −16 |
| `gain` | 线性倍数，默认 0.4（旧语义，保持兼容） |
| `dur` `apex` `pitch` `seed` | 透传给配方：加长尾巴、指定最响点、指定音名、换 take |

**为什么用 `align` 而不是手敲毫秒**：每个音效自带实测 `onset_s / peak_s / end_s`（−1 dBFS 渲染上量的 1 ms 包络）。写 `"align":"peak","lead":0.037` 的意思是"最响点落在切点后 37 ms"，换了音色这条意图依然成立；写死 `"at": 4.537` 换音色就要重调。

## 四、成本实测

| 场景 | 耗时 |
|---|---|
| 单次 CLI 渲染（`earshot sfx render`） | **3.58 s** —— CLI 包装占大头，不要逐条调 |
| 批量脚本渲 17 条（一次进程） | 9.1 s（import 只 0.25 s） |
| 批量渲 40 条角色音 | 9.5 s |
| 缓存命中后混音 | 0.4 s |
| 同片出片：内置音 7.9 s → earshot 首次 13.0 s → **缓存后 8.3 s** | +0.4 s |

缓存 key = `id + dur + apex + pitch + seed` 的哈希，改参数自然换 key。缓存落 `~/.cache/cutduo/esfx/`，每条纹一个 `.wav` + `.wav.json`（存 onset/peak/end），**不入库**。

## 五、自检与降级

- earshot 每条渲染完会跑模型无关自检（点击声、削波、DC、尾部截断、音高爬升、叠击）。**这是 warning 级，不阻断**，会打印原话，如 `pro_typing_key/soft: tail cut at -44 dB re peak`。要消除就给 `dur` 加长或接受（−44 dB 听不出）。
- 找不到解释器时整批降级：按 category 映射到内置合成音（`cut_hit/*`→impact、`whoosh*`→whoosh、`riser*`→rise、其余→tick），并打一条警告。降级结果与 `EARSHOT_PY=none` 字节一致。
- 单条渲染失败只降级那一条，不影响其余。
