# 段级运镜（`src/camera.mjs`）

> 2026-11-14 落地。给 paper / science 补上"摄像机"这个维度。

## 为什么要有

paper 与 science 的画面全是**固定机位 + 元素自己生长**。短片段没问题，长片（90s+）会读成 PPT。

这不是审美问题，是结构问题：观众感知运动有两条通道——**物体运动**和**相机运动**。我们只有前者，所有变化都发生在同一张平面内。段型再多、动画再细，缺了第二条通道，长片的观感就会塌。

同源判断见 huashu-art-motion 的 `references/镜头语言.md`：某支 102 秒、44 镜的片子，代码里推近约 48 次（平均 2.1 秒一次）、几乎不拉远，作者原话是「次数太多，而且节奏太快了，一点都不 smooth」。

## 怎么用

在段的 `args` 里加：

```json
{
  "type": "point",
  "t0": 5.32, "t1": 11.436,
  "args": {
    "words": [["等渲染、", 5.83]],
    "camera": { "kind": "push", "z": 1.10, "dur": 1.0 }
  }
}
```

四种动作（秒数取自 huashu 的实测参数表）：

| kind | 用途 | 参考参数 | 曲线 |
|---|---|---|---|
| `push` | 缓推：带视线到下一处、情绪往前一步 | `z` 1.10–1.15，`dur` 0.6–1.5 | sineInOut，到位后**停住** |
| `pull` | 拉远：回到全貌、段落收束、结尾 | `z` 1.10–1.15（起始放大态），`dur` 0.8–1.2 | sineInOut，落到 1.0 |
| `punch` | 快推：揭晓、反转、关键数字 | `z` 1.18–1.25，`dur` 0.25–0.35 | expoOut（前快后慢） |
| `drift` | 慢漂：氛围镜、艺术风格画面 | `z` 1.03–1.06，整段走完 | 匀速 |

附加字段：`"anchor": [960, 540]` 指定缩放中心，缺省画面中心。

`{"kind": "cut"}` 或不写 `camera` = 现状，**零回归**（实测同帧 PSNR = inf，文件字节数完全相同）。

## 三条硬约束

1. **只放大不缩小。** `z ≤ 1` 会被 `cameraAt` 直接判为无效。原因是段型的背景只画到 1920×1080 边界，缩远会露出画布外的空白。要"拉远"，用「从放大态回到 1.0」表达（`pull`），不要写 `z: 0.9`。
2. **只包内容层。** 时间码、头像卡、字幕、品牌角标、收尾淡出都在变换之外画。已验证：加 `push z=1.10` 后，字幕带与时间码区域 PSNR = `inf`（逐像素不变），只有内容层变化。
3. **段级、不跨段。** 跨段相机要处理"上一镜继续推"（huashu 的 `zoomThrough live`），那需要把相机提到场景之上，与本仓 `renderFrame(t)` 的段内重画模型冲突。要做需单独设计。

## 什么时候不该用

**画面自己在动的段，不要加相机。** huashu 的规则原话是「画面自己在动（实拍录像、正在描的线、正在长的曲线）就更不用动镜头，镜头一动反而抢戏」。

对应到本仓：`chart` / `grid` 这类元素逐个长出来的段型，加缓推会让"数据在长"和"镜头在推"两个运动打架。优先只给**静态构图**的段加（`hero` / `quote` / `outro` / `checklist`）。

## 门禁

```bash
node src/gate.mjs out/x.mp4 --camera-check out/x.vo.json
```

只报不拦（与 gate 既有的三项连续分布指标同口径）。两条线都来自反面标尺：

- 推近 **> 8 次/分** 报黄（那支被判"一点都不 smooth"的片子是 12 次/分，还是下限）
- 重音动作（`punch`）**> 1/3 镜头** 报黄（全篇加粗等于没有重点）

## 单测

`cameraAt` / `cameraStats` 是纯函数，无 ctx 依赖：

```bash
node --input-type=module -e "import('./src/camera.mjs').then(m=>console.log(m.cameraAt({kind:'push',z:1.1,dur:1},0.5,20,{w:1920,h:1080})))"
```

19 个用例覆盖四种曲线、单调性、`z≤1` 拒绝、未知 kind 退化、anchor 缺省与指定、统计阈值。
