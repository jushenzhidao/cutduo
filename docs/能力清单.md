# renderd / mcp.cutduo.com 能力清单

> 依据：`renderd/renderd/*.py`、`renderd/docs/{IR,API,OPS,SECURITY}.md`、线上实测（2026-11-10）。
> 只写能从代码与线上核对到的能力；未实现的集中在最后一节，不写愿景。

---

## 一、一句话定位

**输入一份时间线（IR）或一个模板 + 素材 + 变量，输出成片与一份可判断对错的证据回执。**
面向 Agent 设计：它看不见视频，所以「成功」必须由回执里的结构化断言来定义，不能只返回一个 URL。

```
素材 ──归一化──▶ 编译 ──▶ 渲染 ──▶ 四层校验 ──▶ 回执(receipt) + 证据图 + 成片
                                    │
                             L0 素材决策单 / L1 结构 / L2 感知 / L3 语义
```

---

## 二、四种调用方式

| 入口 | 传输 | 适用 | 证据 |
|---|---|---|---|
| **MCP over Streamable HTTP** | `POST /mcp`，JSON-RPC 2.0，支持 batch(≤32) 与 SSE 响应 | 远程 Agent（WorkBuddy / Claude Code / Cursor） | `api.py h_mcp()` |
| **MCP stdio** | 行分隔 JSON-RPC，stdin/stdout | 本地嵌入，`renderd mcp --tenant` | `mcp_stdio.py serve_forever()` |
| **REST** | HTTP/1.1 Bearer token，22 条路由 | 上传素材、运维、CI | `api.py ROUTES` |
| **CLI** | 本地进程，15 个子命令 | 部署、排障、批量 | `cli.py` |

两条 MCP 传输**共用同一份业务分发**（`MCPServer.handle()`），工具集与错误码只有一套定义。
租户来源是唯一实质差异：stdio 允许 `RENDERD_MCP_TENANT` 兜底，HTTP **只能**来自 Bearer token。

## 三、MCP 工具集（8 个）

| 工具 | 作用 | 关键参数 |
|---|---|---|
| `list_templates` | 列模板及其变量 schema，按 `family` / `aspect` 过滤 | `family?` `aspect?` |
| `validate_render` | **不渲染的预检**：IR 合法性、素材探针、字体覆盖、安全区、成本估算，返回可照改的 `fixes` | `template_id`+`variables`+`assets` 或 `ir` |
| `submit_render` | 提交渲染。**幂等键必填**（同 key 返回同一 job_id，不重复计费） | `idempotency_key`(≥8) `priority?` `callback_url?` `delivery?` `dry_run?` |
| `get_job_status` | 查阶段与进度；失败时返回可执行的错误契约 | `job_id` |
| `get_receipt` | 取证据回执（L0/L1/L2/L3 + 交付结果 + 证据链接） | `job_id` |
| `upload_asset` | 上传素材（base64），返回 `upload:<sha256>.<ext>`；内容寻址去重 | `filename` `content_base64` `kind?` |
| `list_jobs` | 列本租户任务，丢了 job_id 时找回上一次提交 | `limit?`(1–200) `status?` |
| `cancel_job` | 取消**排队中**的任务；已开始渲染的返回 `E_CANCELLED` | `job_id` |

`assets` 的结构已内联在每个工具的 inputSchema 里（`id` / `uri` 必填，`sha256` / `kind` 可选），
不再使用 `$ref: #/$defs/Asset` —— 每个 inputSchema 是独立文档，`$ref` 在里面解析不到。

错误语义：**业务失败走 `result.isError=true` 且 content 内是 `{error:{code,hint,field,allowed_values,retryable}}`**，
不是 JSON-RPC error —— 这样 Agent 能区分「协议错了」和「参数错了」。

## 四、REST 接口（22 条）

| 分组 | 端点 |
|---|---|
| 健康与指标 | `GET /healthz`、`GET /readyz`（含磁盘闸）、`GET /metrics`（12 项，来源白名单） |
| 模板 | `GET /v1/templates` |
| 素材 | `POST /v1/assets`（应用层上限 512 MB，网关放行 600 MB，内容寻址去重）、`GET /v1/assets`、`DELETE /v1/assets/{id}`（在途引用返回 409） |
| 任务 | `POST /v1/render`、`POST /v1/validate`、`GET /v1/jobs`、`GET /v1/jobs/{id}`、`GET /v1/jobs/{id}/events`、`POST /v1/jobs/{id}/cancel`（仅排队中）、`POST /v1/jobs/{id}/replay` |
| 产物 | `GET /v1/jobs/{id}/video`（签名 URL）、`GET /v1/jobs/{id}/receipt`、`GET /v1/jobs/{id}/evidence/{name}`（scope 绑定） |
| 运维 | `GET /v1/queue`（`scope=tenant`/`admin`）、`GET /v1/dlq`、`GET /v1/usage` |
| MCP | `POST /mcp`、`GET /mcp`（405 + `Allow: POST`，让客户端尽快回落到 POST） |

## 五、渲染能力（IR v0.1）

### 输出规格

| 项 | 取值 |
|---|---|
| 视频编码 | `h264` / `hevc` / `av1`（容器 tag 分别为 `avc1` / `hvc1` / `av01`，`hvc1` 是为 Apple 生态专门修的） |
| 音频编码 | `aac` / `opus` |
| 像素格式 | `yuv420p` / `yuv422p10le` / `yuv420p10le` |
| 分辨率 / 帧率 | 任意，帧率用分数（`num/den`），29.97 无累积漂移 |
| 最长 | 216 000 帧（2 小时 @30fps） |
| 调色 | bt709 / tv range，显式写入 |

### 时间线

| 轨道类型 | 说明 |
|---|---|
| `video` | 主视频，支持 `in_frame` / `out_frame` / `speed` |
| `overlay` | 叠加层，**保留 alpha**（归一化透传，编译期 `yuva420p`） |
| `text` | 文字，编译期栅格化成图层（不依赖目标机字体） |
| `audio` | 音乐床 / 配音，支持 `volume` 0–4 |
| `subtitle` | SRT / WebVTT，每 cue 展开为 text clip，走同一套安全区校验 |

### 剪辑能力

| 能力 | 参数 | 备注 |
|---|---|---|
| 画幅适配 | `fit: cover / contain / stretch / blur` | `blur` = 完整画面居中 + 同素材模糊背景（横转竖的标准做法） |
| 转场 | 8 种：`fade` `dissolve` `wipeleft` `wiperight` `slideup` `slidedown` `circleopen` `fadeblack` | 只暴露跨版本稳定的 xfade 子集；MLT 后端未实现，**编译前报错不降级** |
| 音量 | `clip.volume`（0–4） | 与 `target_lufs: null` 配合可关闭响度归一 |
| 响度 | `target_lufs`（默认 -14.0，容差 ±1.0） | L3 断言实测，合成与真实素材都验过 |
| 文字样式 | 字号/描边/对齐/锚点/`max_chars_per_line`/安全区 | 超框直接 `E_TEXT_OVERFLOW`，不静默缩字号 |
| 多轨叠加 | 多 `overlay` 轨 | 实测 50% 混合误差 &lt; 1% |

### 确定性

同 IR + 同后端 + 同引擎版本 + 同字体集 + 同输出规格 + 同线程数 ⇒ **字节一致**（ffmpeg 后端承诺；
MLT 后端未承诺）。缓存键是六元组，不是 IR 哈希。

## 六、素材归一化

上传时按内容寻址（sha256），跑「探测 → 决策 → 归一化」三段，产出 mezzanine 并缓存。
**归一化动作写进回执 `L0_ingest`，digest 进缓存键** —— 禁止静默改变素材语义。

覆盖的故障模式（21 条合成语料 + 真实素材）：

| 类别 | 处理 |
|---|---|
| 色彩标记缺失 | `TAG_COLOR` 补 BT.709（SPS VUI） |
| HDR（HLG / PQ） | `TONEMAP_HDR`：zscale 线性光 + hable → BT.709（**预览级，非广播级调色**） |
| 旋转显示矩阵 | `BAKE_ROTATION` 烤进画面并清元数据 |
| 非方形像素 | `SQUARE_PIXELS` SAR → 1:1 |
| 奇偶/黑边 | `FIX_ODD`（裁 1px）、`CROP_PILLARBOX` |
| 像素格式/帧率不符 | `FORMAT_YUV420P`、按时间线帧率重采样 |
| 无音轨 | `AUDIO_SYNTH` 补静音并写 warning |
| 5.1 / 单声道 | `AUDIO_DOWNMIX`（带 pan 系数）/ `AUDIO_UPMIX` |
| 多音轨 / 内嵌字幕 | `AUDIO_PICK_FIRST` / `DROP_SUBS`（写 warning） |
| 超长 / 截断 / 0 字节 / 纯音频 | `TRIM_OVERLONG` / 提交期抽样解码拦 `E_INPUT_TRUNCATED` / `E_INPUT_UNREADABLE` / `E_INPUT_AUDIO_ONLY` |

## 七、质量验证与回执

| 层 | 内容 | 能否判「首次就对」 |
|---|---|---|
| **L0** | 每个素材被怎么归一化的决策单（actions / warnings / digest） | 是（回答「素材被改了什么」） |
| **L1** | 结构断言 10 项：分辨率/帧率/帧数/像素格式/色彩/范围/采样率/声道/音画时长差/帧数一致 | 是 |
| **L2** | 感知层（VMAF/SSIM/PSNR） | **否** —— 无 reference 时恒为 `applicable=false`，不假装通过 |
| **L3** | 语义层：字形覆盖、安全区、响度、黑场 | 是（唯一能判首次正确性的层） |

证据（4 件，均带 sha256，可检出替换）：
接触表 `contact_sheet.jpg`、首帧、尾帧、波形图 `waveform.png`。

回执 `verdict: pass|fail` + `failures[]` + `warnings[]`；**交付失败会把 verdict 降级为 fail**，
不会出现「文件在本地但客户拿不到却判 pass」。

## 八、异步与可靠性

| 机制 | 实现 |
|---|---|
| 幂等提交 | `(tenant, idempotency_key)` 唯一；重复提交返回同一 job_id |
| 原子领取 | 单语句 `UPDATE … RETURNING`（SQLite）/ `FOR UPDATE SKIP LOCKED`（PG），多 worker 不双领 |
| 租约与回收 | `lease_until` + 独立 reaper；崩溃任务自动重排（实测 `kill -9` 后自愈，attempts=2） |
| 重试分类 | `transient`（超时/OOM/编码会话）才重试，`permanent` 立即失败；退避 `base × attempts²` |
| 死信 | `GET /v1/dlq`、`POST /v1/jobs/{id}/replay`、`renderd release --worker` |
| 背压 | `RENDERD_MAX_QUEUE_DEPTH`（默认 2000）、`RENDERD_MAX_TENANT_INFLIGHT`（默认 8）→ 429 `E_QUEUE_FULL` |
| 优先级 | `priority: low / normal / high` |
| 取消 | **仅排队中**；运行中需等结束（`E_CANCELLED` 明确说明） |
| 时间基 | 逻辑时钟（HLC），墙钟跳变不导致误回收 |

## 九、交付

| 模式 | 说明 |
|---|---|
| `local`（默认） | 成片留在服务本地卷，返回 HMAC 签名 URL；签名绑定 `tenant + scope(video / evidence:<name>)`，换租户或换用途一律 401 |
| `put_url` | 直传客户自己的预签名 PUT 地址，不经过我方出口带宽，服务不持有客户凭据 |
| webhook | 任务终态回调：解析一次、钉住 IP、投递期零解析（防 DNS rebinding）；`event_id = job_id:status:attempts` 可去重 |

## 十、多租户与安全

| 项 | 实现 |
|---|---|
| 身份 | `Authorization: Bearer <token>` → 租户；`RENDERD_ADMIN_TOKENS` 是 token 子集，只多「看全局视图」权限 |
| 配额 | 每租户 `qps` / `monthly_minutes` / `storage_mb`（线上实测 **10 / 1000 / 2048**）。时长配额**含在途预占**：`billed_seconds` 在提交时写入，任务离开 accepted/running 后自动失效，成功转用量、失败释放 |
| 限流 | 共享存储仲裁（20×50 ms 子桶滑窗），多副本不放大；错 token 按 IP 前置拦截 |
| 存储配额 | `assets` + `asset_refs` 双层记账，删引用即释放；内容寻址去重，付费方删除不影响他人 |
| 出站防线 | `netguard`：协议白名单、私网/元数据地址拒绝、**钉 IP 投递**（防 rebinding） |
| 头注入 | 出站 header 净化（拒控制字符、受保护头） |
| TLS | 两层：应用内置 + 网关（Caddy / 宝塔 nginx），`/metrics` 来源白名单 |
| 审计 | `audit` 表：提交、下载（含 signed）、取消、replay 均落库 |

## 十一、可观测

| 面 | 内容 |
|---|---|
| `/metrics` | 12 条时间序列：`cache_entries`、`cache_hits_total`、`clock_skew_seconds`、`failed_jobs_24h`、`jobs{status,stage}`、`jobs_running`、`jobs_total`、`queue_delayed`、`queue_depth`、`queue_oldest_wait_seconds`、`queue_ready`、`uptime_seconds`。**已知缺陷**：`renderd_tenant_inflight` 有 HELP/TYPE 声明但没有任何样本（HELP 块改名时漏改），同时 （2026-11-10 已修：空闲时也发 0 值、HELP/TYPE 与样本一一对应，并有回归用例 `test_02b`） |

| 日志 | MCP 一行一调用（rid / tenant / method / tool / client / outcome / code / job / ms / slow=1）；nginx 侧另有 `perf.log`（rt / urt / uht） |
| 自检 | `renderd doctor`（环境、字体、ffmpeg 能力、DB、令牌一致性） |

## 十三、**不支持**的能力（明确边界，避免误期待）

| 能力 | 现状 |
|---|---|
| 转场（MLT 后端） | 未实现，编译前 `E_IR_UNSUPPORTED` 报错，不静默降级成硬切 |
| 音量自动化 / ducking（sidechain） | 未做，需先扩 IR（关键帧序列 + sidechain） |
| HDR 交付 | 只做预览级 tonemap 到 BT.709，没有创作意图（高光滚降/肤色需人工） |
| GPU 编码 | 无（Colima 无 GPU，镜像未编 nvenc / videotoolbox） |
| 运行中任务取消 | 不支持，只能取消排队中的 |
| 服务端推送（SSE 主动流）/ MCP tasks | 不支持，完成检测只能轮询；`GET /mcp` 明确回 405 |
| MCP 内上传素材 | 无上传工具，素材必须走 `POST /v1/assets`（REST）后用 `upload:<name>` 引用 |
| MCP resources | `resources/list` 返回空（契约里描述过 2 个 resource，运行时未实现） |
| 字节确定性（MLT） | 未承诺 |
| 多机共享存储 | 产物走本地卷；PG 可扩副本但文件卷不能 |
| 真实客户素材回归 | 只用 21 条合成语料 + 1 条公开 promo 验过，未做 50–100 条真实素材回归 |
