## 六·五、补记：integrity 的反向检查（同日补）

补 `sketchnote` 的 integrity 时发现检查器还有一个盲区：

**它只做正向检查**——遍历 `integrity.json` 列出的文件比对哈希。
如果**目录里有、清单没列**的文件，它看不见。

实测：给 `chalkboard` 加了 `tools/vo.py` 后，integrity 只有 22 条、不含该文件，
却照样报「22/22 通过」。integrity 本来的意义是「这份源码的完整清单」，
漏掉新增文件就等于清单不可信。

已补反向检查（与 `build-template.py` 的收录规则对齐：排除 `integrity.json` 自身、
点开头文件、`_raw.*`、`.psd/.xcf`，以及 `out/render-cache/node_modules/.git/__pycache__`）：

```
chalkboard   ✓ integrity 22/22 通过   ! integrity 缺少 1 个文件（新增后没重新打包）：['tools/vo.py']
```

## 七、一个自省

批量修 `voicing.tool` 时，我把 `sketchnote` 和 `science` 一起改成了 `tools/build-sync.py`——
它们**自带** `tools/vo.py`，原本是对的。发现后立即恢复。

根因是我只看了「仓库根有没有 `tools/vo.py`」，没意识到 `guide.json` 里的路径是**相对模板目录**的。
教训与 A 类完全相同：**判相对路径，先确定基准目录。**
