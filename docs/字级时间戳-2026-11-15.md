# 字级时间戳：把"画面追声音"做实

> 2026-11-15 · 起因是《一次渲染到底慢在哪》重做。原版 53.7s / 8 段，段内按线性进度揭示，
> 念到第三个词时图上只长出一个。重做把片长压到 20 秒、3 段 5 句，每项绑一个词。

## 一、先否掉一条便宜的路

直觉上，配音是我们自己用 edge-tts 合成的，TTS 引擎应当知道每个字的时刻，不必上 ASR。
实测否掉：

| 版本 | 结果 |
|---|---|
| edge-tts 7.3.1 | 只有 `SentenceBoundary`，整句一个边界，**没有 WordBoundary** |
| edge-tts 6.1.12 / 6.1.9 | 握手直接 403（旧版内置的 TrustedClientToken 已失效） |

所以 `--write-subtitles` 那条路拿不到中文词级时刻。要么换 TTS（要 API 和计费），
要么上强制对齐。选后者。

## 三、对齐：为什么逐句切窗

整段识别会让一个错字污染后面整句的锚点。`vo.mjs` 已经知道每句的 `audioAt` 与 `speech`，
按句各切一个窗口（两侧各留 0.12s），一句一个识别上下文，错字不外溢，还能单独算 match 分。

窗口内的识别串与稿子做 `difflib.SequenceMatcher` 字符级对齐：

- `equal` —— 直接用识别到的时刻
- `replace` —— 按该段的起止时刻把稿子这一段铺开（同音字、连读都在这里）
- `delete` —— 夹在前后锚点之间插值（识别漏字）
- `insert` —— 忽略（识别多出来的字不影响稿子）
- 标点 —— 跟随前面最近的发音字，句首标点跟随后面

**同音字不算错**：对齐看位置不看读音。第 2 句把"帧"识别成"针"，match 0.96，
锚点照样落在正确的字上。

实测：`match = 1.00 / 0.964 / 1.00`，低分句会被打印出来要求人听。

## 四、契约：两组锚点，不能合一

```json
{ "label": "skia-kit", "value": 6.8, "rowAt": "三个引擎", "at": "六点八" }
```

- `rowAt` 管"是什么"（行标签先立住、条还是空的）
- `at` 管"多大"（条长、数值）

合成一组的话，念到"三个引擎"时三条已经长满，后面报数就成了复读。分开以后实测：

| 绝对时刻 | 画面 |
|---|---|
| 0.42s | 三行标签出现，条全为 0 |
| 4.70s（"六点八"） | 第一根条长出来，6.8 |
| 5.70s（"五十一"） | 第二根，51 |
| 6.58s（"一百一十三"） | 第三根，113 |

`compare` 也用同一套：`rowAt` 控左列、`at` 控右列，于是"慢的那台"先把左列立住，
"不开浏览器"才把右列亮出来 —— 对比的悬念留住了。

**负向自检**（必须做，否则写错的锚点表现为"某项永不出现"）：
把 `at` 改成稿子里没有的"五十二"，`render.mjs` 打印

```
锚点词不在口播稿里：「五十二」(at)
  稿：同一段四十六秒的口播，三个引擎差了十六倍。……
```

并返回退出码 2。越界（时刻 > 段长）、顺序倒（后一项比前一项早）同样拦。

## 五、这一版踩到的坑

1. **字幕压注释**：`captionY 946` 配默认 `frame.bottom 120`，版心底缘 960 正好压在左下角
   `note` 上。样张不设 note 时看不出来，成片才暴露。→ `frame.bottom: 210`。
2. **一段多句**：锚点常落在段内第二句（先给结论再报数），原来"一段一句"装不下。
   `lines: ["…", "…"]` 逐句合成、句间插 `lineGap`，字幕按句切换（两句一起挂超 26 字上限）。
3. **响度**：`vo.mjs` 出的 wav 实测 **−19.9 LUFS**，偏离 −16±2，交付前必须
   `loudnorm=I=-16:TP=-1.5:LRA=11`。
4. **loudnorm 会拉长音频**：重采样让容器变成 20.200s，`gate` 立刻报"帧数 604 ≠ 20.200×30=606"。
   加 `-shortest` 对齐。
5. **开场空镜**：标签锚点原本落在"三个引擎"（2.38s），前 2 秒只有标题，`gate --blank` 报疑似空镜
   （信息量 11.4 < 12）。→ 把 `rowAt` 提前到第一句开头的"同一段四十六秒"，`hook` 也从 0.14 升到 0.15。
6. **2–3 条时版面偏空**：`data-bar` 行高上限 110，3 条只占 366px，下面空 350px。
   → 上限提到 190 + 整块垂直居中 + 条高/字号跟行高联动。
